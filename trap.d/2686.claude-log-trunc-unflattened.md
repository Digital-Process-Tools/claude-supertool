Whether that exclusion claim actually holds is what's unsettled, not confirmed
false: `trunc()` is called from `tail.py`/`list.py`/`summary.py` on
`event_content_parts()`'s session-transcript message content read out of local
JSONL session logs. A session transcript is a local file, but its *content* can
include text a tool fetched from elsewhere mid-session -- a WebFetch result, a
pasted issue body, a tool output copied verbatim into the log -- which is "text
somebody else wrote" in substance even though the file it currently lives in is
on the local disk. `presets/_repo_target.py:363`'s sibling exclusion in the same
family is different in kind: it does the CRLF collapse and then runs every
character through `isprintable()` (line 368), which independently covers the
rest of the separator set, so THAT exclusion is justified by what the code does
downstream, not by an assertion about where the text came from. `claude-log`'s
`trunc()` has no such downstream sweep.
