Building a test for #2256 that monkeypatches `sys.stdout` to a real
`io.TextIOWrapper` on a legacy codepage, then calls a preset's `main()` and
reads what actually got written: doing the `monkeypatch.setattr(sys,
"stdout", stream)` inside a pytest *fixture* (returning the stream object to
the test) silently does not work. Inside the test body, `sys.stdout is
stream` reads `False` — it is pytest's own `_pytest.capture.EncodedFile`
capture wrapper instead — even though the fixture just set it, and the
BytesIO buffer behind the wrapper reads back empty after `main()` runs, with
no exception anywhere. This happens with plain default capture (no xdist,
no coverage needed to reproduce it) — pytest re-resumes its own capturing
around each of setup/call/teardown separately, so a `sys.stdout` object set
during the *setup* phase (which is when a fixture body runs) is overwritten
again before the *call* phase where the test function itself — and the code
under test's prints — actually execute.

Cost: about 30 minutes across two failed diagnosis passes (first suspected
pytest-xdist parallelism, since the default `addopts` in this repo's
`pyproject.toml` is `-n auto`; ruled that out with `-n0` and it still failed;
then suspected `capsys.disabled()` would fix it — it does not, because
requesting the `capsys` fixture at all makes pytest actively manage
`sys.stdout`/`sys.stderr`, and `capsys.disabled()` restores the *original*
real stdout for its block, not whatever a sibling fixture set it to,
discarding the fixture's monkeypatch just the same). The only reliable fix:
do the `monkeypatch.setattr(sys, "stdout", ...)` call directly inside the
test function body, not inside a fixture it calls into and receives a value
from. `tests/test_untrusted_console_encoding_863.py` in this repo already
uses exactly that shape (a plain helper function called from inside each
test, not a fixture returning the stream) — for what was presumably the
same reason, though nothing in that file states it — which would have saved
the diagnosis time if noticed first.
