- **The path chokepoint's own detector read `syntax` and nothing else, so an op whose `cmd` uses `{file}` was never asked to declare a boundary** ([#1350](https://github.com/Digital-Process-Tools/claude-supertool/issues/1350)).

  [#1287](https://github.com/Digital-Process-Tools/claude-supertool/issues/1287)'s rule is that an op naming a path and declaring nothing is **refused, not skipped** — a path argument reaching no check is an unchecked read, not a check that could not run. Its detector inverted that for one input shape: an op whose `syntax` names no path, or which carries no `syntax` key at all, took the `return None` arm. No declaration demanded, no check run, and a verdict indistinguishable from declared-clean. Two states inside the guard that exists to insist on three.

  **The detector now reads the `cmd` template too, and the two are OR'd rather than ranked.** `{file}` and `{dir}` are the core's own placeholders, so an op writing one has already said which argument it means a filesystem path to be. The ordering was measured, not assumed: of the 24 shipped ops the `syntax` detector finds, **zero** carry either placeholder, so letting `cmd` supersede `syntax` would have disarmed the gate for every one of them. Going the other way, exactly **one** shipped op is found by `cmd` alone — `oss_train`, in this repo's own `.supertool.json`, which now declares `"paths": {"args": []}` because its argument is a worktree name bounded by `wt_root` inside the script ([#1246](https://github.com/Digital-Process-Tools/claude-supertool/issues/1246)), a boundary neither `cwd` nor `repo` can express.

  **`{arg}` is deliberately not a signal**, though it substitutes the very same argument `{file}` does. Sixteen shipped ops pass a handle, a ref, a tag, an ID or a repo slug through it and none takes a path; promoting it would refuse all sixteen and gate nothing.

  The refusal now names the signal that fired. An op with no `syntax` was being told it "names a path in its syntax ()", which reads as a bug in the guard rather than a demand on the op.
