- The jit rule-body budget counts content, not the checkout. `tests/test_jit_rule_body_budget_1433.py` measured each rule body with `stat().st_size`, and git checks these files out with the platform's line endings — so a `windows-latest` leg counted one extra byte per line for byte-identical content and reported a size that exists on no machine the author has. PR #1768's `presets-git.md` is 5,918 bytes / 94 lines with LF and failed all four Windows legs of run #31912614030 at 6,012. The count now collapses CRLF to LF first, and the test states what the number claims and what it deliberately does not: on a CRLF checkout the hook does inject those CRs, which is a property of the checkout to fix at checkout time, not a body the author can shrink. A rule the index names but nobody can read is now reported as unmeasured rather than dropped before the measurement (#1799).
