- **`_PARALLEL_SAFE_OPS` was documented "read-only" and carried `format_staged`, which rewrites every staged file** ([#1244](https://github.com/Digital-Process-Tools/claude-supertool/issues/1244)). Two things read that set, and it was the wrong answer for both. `_main` runs a whole batch on a thread pool when every op is safe, so under `SUPERTOOL_PARALLEL` a formatter's write raced a sibling `read` of the same file: `supertool 'format_staged' 'read:f.txt'` returned the **pre**-format bytes, under `[complete file — no more lines]`, while the post-format bytes were already on disk. Sequentially the identical call was right, so a performance switch changed an answer. And `dispatch` skips `_path_meta_bulk_drop()` for a safe op, leaving the repo-wide `git status` snapshot standing across a write that changed the tree it describes.
- **The judgment call was whether the op leaves the set or the set gets a new name**, and it is the op. "Safe to run concurrently" is not a weaker contract this could retreat to: parallel safety is a property of the whole set of ops in one call, and a writer is unsafe beside any reader of the same path. Only two things in the core consult the predicate and both ask whether the op writes.
- **Not `destroys`, and it did not block a release.** The formatter's write lands; what is wrong is the answer rendered beside it. `parallel` is off by default, so reaching it takes an opt-in.
- **The two declarations can no longer drift.** `_OP_SAFETY_BUILTIN` has said `format_staged: "writes"` since [#1231](https://github.com/Digital-Process-Tools/claude-supertool/issues/1231) — whose own comment says in as many words that this set is not a read-only oracle, which is why #1231 declared each op's class at its site rather than deriving it here. `tests/test_parallel_safe_writes_1244.py` now asserts every member of `_PARALLEL_SAFE_OPS` that `_OP_SAFETY_BUILTIN` knows about is declared `read-only`, so two sources for one truth cannot disagree again.
- `docs/configuration.md`'s "Safe ops" list was stale in the other direction — it had been missing `validate`, `validate_staged`, `workspace`, `resolve`, `diag`, `hover` and `help` since they joined.
