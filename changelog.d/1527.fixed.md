- `phpstan` no longer reports a whole file `skipped` because a refusal phrase appeared somewhere in its output. The check ran `refusal.is_refusal` — a lowercased substring test — over `stdout` and `stderr` concatenated, and fired ahead of the two error arms below it, so a stock phrase in PHP bootstrap noise or any `PHPSTAN_SKIP_PATTERNS` entry the repo added turned a run that had *reported* into a non-verdict. Under `--error-format=json` the report is one JSON object on stdout and a declination is on stderr with stdout empty, so a skip now requires stdout to hold nothing beyond the refusal statement itself; anything else there means phpstan reported and the adapter could not read it, which is an `adapter` error and exits non-zero. That exit code is what the defect cost — neither verdict rolls back an edit, so the issue's `rollback_on_fail` framing does not hold (#1527).
- `phpstan`'s `phpstan output not json` error now carries the bytes that would not parse, capped at 200 characters, instead of naming the fault and none of its evidence (#1527).
