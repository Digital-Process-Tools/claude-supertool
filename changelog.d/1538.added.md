`bin/supertool-workspace` opens a Claude session over this clone's radar with the watch channel armed. Both halves are easy to get wrong on their own: `radar` reads its tiers from the CWD's project root, so the directory is the board selection, and `<channel>` events only reach a session started with the development-channel flag — without it the pollers still spawn and nothing reads them. The clone is resolved from the script's own location rather than from `$HOME`, so a symlink into `~/.local/bin` works for any checkout, the same route `supertool` already takes (#1538).
