- **A gh outage no longer renders as "cwd is not a GitHub repo"** ([#1789](https://github.com/Digital-Process-Tools/claude-supertool/issues/1789)). `gh-pr-merge` reached `no_repo_error()` on *any* failure of its identity read and dropped the reason it was holding, so during a GraphQL outage it told a working clone of a real repository that it was not a GitHub repo — and its third remedy, *run gh directly with --repo*, routes that op onto raw `gh pr merge`, which the raw-command guard refuses and which skips the leg reconciliation and the post-merge read-back. `no_repo_error()` now takes gh's own error and tells *asked, there is no repository here* from *could not ask*, naming the reason and asking for a retry instead of a `cd`. It takes the reason rather than looking the repository up itself: the other twelve call sites match gh's stderr before they call, so a second lookup here could contradict a correct measurement with a fresher one. `cwd_slug()` keeps the two states #1701 gave it, for the reason #1701 gave.
