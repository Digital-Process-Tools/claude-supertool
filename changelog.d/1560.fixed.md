- `_dropped_tokens_refusal` told the caller to widen a `{file}` template to `{args}` — the exact manoeuvre the module declines to make internally, and for the stated reason that it puts a second path downstream of the containment check. Measured on a fixture op declaring `"paths": {"args": [1], "root": "cwd"}`: position 1 was refused and, after obeying the advice, position 2 printed a file outside the boundary. For an op that declares a containment boundary the refusal no longer offers that remedy at all. It names the positions the declaration actually gates, says that extending the `args` list alongside a widened template is necessary and not sufficient — a fixed index list holds an unbounded `{args}` tail only up to the highest index it names — and states that there is no one-line `cmd` change that keeps such an op contained. An op declaring `"args": []`, or none at all, keeps the plain remedy (#1560).
