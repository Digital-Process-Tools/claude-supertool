- **Every GitHub Action in CI is pinned to a commit sha, not a moving major tag** ([#925](https://github.com/Digital-Process-Tools/claude-supertool/issues/925)). `actions/checkout@v7` is a branch-like ref: its publisher repoints it on every patch release, so the code that runs in this repo's CI with this repo's `GITHUB_TOKEN` could change between two runs of the same commit, with no pull request anywhere. All ten references across `tests.yml`, `slow-tests.yml` and `changelog.yml` now name a 40-character sha with a trailing `# vX.Y.Z` comment, and `tests/test_ci_action_pinning_925.py` refuses a tag pin or a sha without that comment.

  `.github/dependabot.yml` read as coverage for this and was not — it will never bump `v7` to `v7`. Sha-pinning inverts that rather than adding a chore: Dependabot *does* bump a sha-pinned action, rewriting both the sha and the version comment, so an upstream release now arrives as a reviewable weekly PR instead of arriving silently.
