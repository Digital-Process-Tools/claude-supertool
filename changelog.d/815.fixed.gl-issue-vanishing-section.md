- **A failed related-MR lookup no longer vanishes `gl-issue`'s whole section** (found while building [#815](https://github.com/Digital-Process-Tools/claude-supertool/issues/815), and worse than what it reported). `if mr_result.returncode == 0:` had no `else`, and the enclosing `except (subprocess.TimeoutExpired, json.JSONDecodeError): pass` swallowed the rest — so a query that failed printed **no `Related MRs` line at all**. A missing section reads as "this issue has no MRs", which is the signal that an issue is unclaimed, and the action that invites is delegating work that has already been done. That is [#780](https://github.com/Digital-Process-Tools/claude-supertool/issues/780) item 1, fixed on the GitHub side and still live here; `gh-issue` at least printed `Linked PRs: unknown`.

  #815's own comment states that neither family omits the section. That is true at *zero* — both print an explicit `none`, which is what was verified there — and it was not true on failure.

  The section now prints `Related MRs: unknown — could not query (...)` on a non-zero exit, a timeout, unparseable output, and an unexpected JSON shape. `Related MRs: none` still means an answered zero, and nothing else does.

  **Including the spawn failure, which escaped the old handler entirely.** `glab` missing from `PATH` raises `FileNotFoundError` from `subprocess.run` — `[WinError 2] The system cannot find the file specified` on Windows — and `PermissionError` where POSIX raises `IsADirectoryError` ([#618](https://github.com/Digital-Process-Tools/claude-supertool/issues/618)/[#627](https://github.com/Digital-Process-Tools/claude-supertool/issues/627)). Neither was in `except (TimeoutExpired, JSONDecodeError)`, so the op raised through the code whose entire job is to say "I could not ask" — [#997](https://github.com/Digital-Process-Tools/claude-supertool/issues/997)'s mechanism. `OSError` is caught, not one platform's spelling of it.

  The same arm was missing from `gh-issue`'s `_print_linked_prs`, whose `main()` guards its own `gh` call with `except FileNotFoundError` while the linked-PR lookup did not. Both are covered now, and both are pinned by tests that raise `FileNotFoundError` and `PermissionError` explicitly rather than relying on a platform to produce one.
