- **`watches` reports the fleet's shared GitHub API budget, and gh-backed pollers back off on a real rate limit** ([#2509](https://github.com/Digital-Process-Tools/claude-supertool/issues/2509)). Every `gh-branch`, `gh-run`, `github-pr`, `github-pr-feed` and `github-issue-feed` poller on a machine authenticates as the same keyring token — 18 pollers at the shipped 30s interval already project past the 5000 req/h core budget on their own. `watches` now prints the projected requests/hour across every channel the cross-channel scan sees, next to a live `gh api rate_limit` read, with a `WARN` when the projection exceeds it. On an actual rate-limit failure the poller's own `*_unreachable` event now carries `retry_after`, and the poll loop sleeps until that reset instead of hitting the same wall on the next ordinary `INTERVAL`. `SUPERTOOL_WATCH_INTERVAL` overrides every source's own `INTERVAL` fleet-wide, for a machine running several repositories' channels at once.
