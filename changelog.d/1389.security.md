- **The raw-command guard is no longer blinded by a `#` comment, a wrapper word, an absolute path, a brace group or a line continuation** ([#1389](https://github.com/Digital-Process-Tools/claude-supertool/issues/1389)). Six shapes each hid a raw command from the gate that ships enabled by default, and every one returned `clean` — so the hook stayed silent and the command ran, which is the sentence the guard was built to make impossible, true of the guard itself.

  Every one was the matcher disagreeing with the shell about **where a command starts**, so the fix is one answer rather than six patches. Comments are now stripped line by line inside the quote-aware scan that already rewrites newlines — `shlex`'s own `commenters` runs to the end of its input, and since that input is the whole command, one `#` on line one hid every line under it. A backslash before a newline is deleted as the line continuation it is, instead of reaching the lexer as an escape that glued the next line's command word onto the previous token. `{` and `}` are separators, so a grouping construct no longer pushes the real command word to index 1. The command word is compared by the name a shell would run, on either path separator and with a Windows executable suffix removed, so `/opt/homebrew/bin/gh` is the `gh` the registry declares.

  And the wrapper words: `env`, `timeout`, `nice`, `ionice`, `stdbuf`, `setsid` and `doas` join the prefix list, but the list is not the fix. Each of those takes options of its own before the command word, and writing down seven option grammars is case work that goes stale one utility at a time — each gap a silent bypass. What is true of every wrapper is weaker and enough: the command word is somewhere further along the same segment. So inside a wrapper-led segment every suffix is offered to the registry, which catches `env -u FOO gh …`, `timeout -k 5 60 gh …` and `sudo -u somebody gh …` without knowing anything about `env`, `timeout` or `sudo`. Outside one, nothing changes: `echo gh pr view 1` runs nothing and is not blocked.

  `tests/test_guard_command_word_1389.py` is a table of shapes rather than a test per fix, in both directions — fourteen commands the shell would run and the guard must block, four it must stay out of the way of. The next bypass is the shape nobody listed, so it costs one row.
