- **`_merge_presets` now warns when a `builtin-ops.<op>` entry is not a table, instead of storing it silently** ([#2308](https://github.com/Digital-Process-Tools/claude-supertool/issues/2308)). #2079 fixed this ONE layer above — `registry:OP` could not disclose a malformed `builtin-ops` entry byte-identically to no override at all — but every runtime reader downstream (`_get_op_int`, `_get_op_bool`, `_grep_file_includes`) still fell back to its own default with nothing recorded, indistinguishable from the key never having been set. A preset carrying `builtin-ops.read = "not-a-dict-oops"` now appends a `_preset_warnings` entry naming the preset, the key, and that every runtime reader will fall back to its default — the same channel `_merge_presets` already uses for a missing preset file or an unparseable manifest, so no new surface was needed to say it.
