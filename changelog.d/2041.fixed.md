- **`docs/presets/slack.md` now walks through minting a token instead of naming only the destination URL** ([#2041](https://github.com/Digital-Process-Tools/claude-supertool/issues/2041)). The old single bullet was correct in every fact and cost a round trip anyway: nothing told a first-time reader the desktop app's own Preferences has nothing related, that *Create New App*'s manifest route sets the OAuth scope for you, that `chat:write` exists under both Bot and User Token Scopes tables, that *Install to Workspace* can raise an admin request instead of minting a token, or that the app has to be created in the same workspace as the target channel (a mismatch authenticates fine and then fails `chat.postMessage` with `channel_not_found`). A numbered sequence covers all five, plus the `xoxp-` user-token route -- it works today, skips the bot's `/invite` step, and trades away the `author_is_viewer` signal the paired watch source computes. `presets/slack/_auth.py`'s own docstring moves with it.
