- **The commit receipt names a non-ASCII path as itself** ([#1137](https://github.com/Digital-Process-Tools/claude-supertool/issues/1137)). `git diff --cached --name-only` runs paths through `core.quotepath`, so `café.txt` reached the `Files committed:` listing as an octal-escaped, double-quoted `"caf\303\251.txt"` — a rendering that is not the path and does not paste back as one. The read is now `-z`, matching what the refusal path has used since [#1003](https://github.com/Digital-Process-Tools/claude-supertool/issues/1003).

  Long-standing and survivable while the caller had typed the path list and already held it. `--all` is what makes it matter: there the caller typed nothing, and that listing is the only record of what was committed.
