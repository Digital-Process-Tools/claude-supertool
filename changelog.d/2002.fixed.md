- **`map`'s regex tier now says when it could not read a class's heritage, instead of rendering that silently as "no parent"** ([#2002](https://github.com/Digital-Process-Tools/claude-supertool/issues/2002)). A class header longer than the 2000-character scan window used to render with no hierarchy and no notice — byte-identical to a class that genuinely has no parent. It now renders `ClassName < ?` for the keyword-based languages where a truncated window can hide a real base class or interface (`_class_header_text` already told the two states apart; the marker was the missing half). Regex-tier only — the tree-sitter tier has no window and is immune, and Python/Ruby headers match at the head of the header regardless of where the window ends.
