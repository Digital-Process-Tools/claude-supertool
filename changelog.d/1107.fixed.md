- **The global-lifetime guard checked "is this a mutable container"; the property it is named for is "does this carry state between calls"** ([#1107](https://github.com/Digital-Process-Tools/claude-supertool/issues/1107)). A `str`, `bool` or `None`-sentinel memo carries state across calls exactly as a cache dict does, and no `isinstance` over `dict`/`list`/`set` can see one. The core has 27 module-level names a call rebinds, and 19 of them held no declared lifetime anywhere: 10 were probe flags the test fixture restored by hand with no declaration, and 9 were classified by nobody.

  **The new check is decidable from the source and needs no type judgement**: `tests/test_core_global_lifetimes_1107.py` fails the build on any module-level name declared `global` inside a function — the only way Python can rebind one from a call — unless it is in `conftest.RESET_GLOBALS`, `conftest.RESET_EXEMPT_GLOBALS`, or the newly-named `conftest.FIXTURE_RESTORED_GLOBALS`, which is the autouse fixture's own save/restore block and is verified against that block's source rather than believed. Deliberately not "classify every module-level name", which [#686](https://github.com/Digital-Process-Tools/claude-supertool/issues/686) rules out for the reason that matters: a guard that is 90% noise gets exempted without reading.

  The sibling was renamed rather than widened — `test_every_mutable_container_global_in_supertool_py_is_accounted_for` — because neither check subsumes the other. `_WRITE_WARNINGS.append(...)` mutates in place and needs no `global`; `_VALIDATOR_MEANING_VERSION = h(...)` rebinds and is no container.

  **Nine names were unclassified, and three of them were armed.** `_VALIDATOR_MEANING_VERSION` (the case the issue was filed from) and `_UNTRUSTED_FLAT`/`_UNTRUSTED_FLAT_TRIED` are built at first use from `_INSTALL_DIR`, which tests patch — [#1322](https://github.com/Digital-Process-Tools/claude-supertool/issues/1322)'s mechanism, in types that guard cannot reach. A memo built under a patched install dir keys the validator cache to a directory that no longer exists, and a failed `_untrusted` probe silently downgrades every later secret in that worker to `repr()`. `_GREP_EXTENSIONS_EFFECTIVE` memoises `builtin-ops.grep.extensions` out of a config the fixture blanks per test. All nine now declare a lifetime, and `_reset_module_state` rebinds anything that is not a live container, since `current[:] = pristine` raises `TypeError` on a bool and reaches nothing on a str.
