- **`slack_publish`'s permalink lookup no longer collapses a transport error, a Slack-level refusal, and a genuinely absent permalink into the same silent nothing** ([#2074](https://github.com/Digital-Process-Tools/claude-supertool/issues/2074)). Before this fix, `fetch_permalink` returned `""` on all three, and the caller printed the `URL:` line only when it was non-empty -- so an operator reading a receipt with no `URL:` line could not tell "Slack has no permalink for this" from "the lookup failed". `fetch_permalink` now returns `(permalink, note)`, and `slack_publish` prints a distinguishable `(no permalink: ...)` line naming which of the three happened.
