- **The plugin identifier is now `supertool-cli`** ([#2736](https://github.com/Digital-Process-Tools/claude-supertool/issues/2736)). The Anthropic directory held the plugin submission on `NAME_CONFUSABLE`, twice, against `name: "supertool"` -- close to the directory connector `suger-mcp` and to publisher "Superr". Measured through the portal's ValidatePlugin API: a `displayName` change alone left both findings; `name: "supertool-cli"` cleared both with no new finding.

  The `supertool` command, the binary, the repo name and the op syntax are unchanged -- only `.claude-plugin/plugin.json`'s `name` field and the install command move. Everyone who already has it installed runs, once:

  ```
  /plugin install supertool-cli@dpt-plugins
  ```

  after the DPT marketplace's own entry is renamed with a `renames` map, which migrates `enabledPlugins` automatically on the next session.
