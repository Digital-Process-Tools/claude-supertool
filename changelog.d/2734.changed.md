- The directory build no longer ships `bluesky`, `devto`, `hashnode`, `slack` or `youtube` (#2734): each reads a credential and sends it to its own vendor's API, the shape the Anthropic directory's `MCP_FORWARDS_CREDENTIAL_ENV` hold fired on (#2732). `.github/release-branch.json`'s `deny` list now drops each preset's manifest and directory, plus `presets/watch/sources/slack/` (its poller dynamically loads `presets/slack/_auth.py` at import time) and the two named `-engagement` watch sources; `master` and the DPT marketplace install still carry all five. A project config that still names one of these presets gets told so by name ("preset 'devto' is not in this build (directory install); install supertool@dpt-plugins for it"), not a bare "not found" -- `_supertool_config._DIRECTORY_BUILD_EXCLUDED_PRESETS` is the list both the message and a new test key off. README.md, README.release.md and docs/presets/index.md say which presets the directory build leaves out and why.
- `_supertool.py`'s own `import socket` and its dynamic `os.environ[name]`-by-loop-variable restore of `SUPERTOOL_REPO`/`SUPERTOOL_REPO_FROM_OP` are gone from the core residual file (#2734), part of the same hold's aggregate citation. `socket` moved to `_supertool_mcp.py`, the one part that actually uses it; the env restore is now two literal-keyed statements instead of a loop over a names tuple. Both are behaviour-neutral -- confirmed by the existing `repo:` pre-pass and MCP client test suites, unchanged and green.
