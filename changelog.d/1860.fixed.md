- **The doubled-backslash payload refusal fired on two backslashes and not on four, so the more likely reflex wrote silently** ([#1860](https://github.com/Digital-Process-Tools/claude-supertool/issues/1860)). `_EXACT_DOUBLE_BACKSLASH` matched a run of *exactly* two, and two tests pinned the exemption on the ground that "three or four were counted, not produced by escape reflex". Four was produced by escape reflex, twice — and the mechanism the original rationale could not have had is that **the refusal manufactures its own blind spot**: four is what a caller writes immediately after reading the two-backslash refusal and doubling again to escape the escape, at the moment they are thinking hardest about backslashes. The guard's own stated premise — the run reaches disk at full length, passes every validator, and is wrong only in string contents — was always as true of four as of two.

  The test is **evenness**, not length: 2, 4 and 6 are refused, and 1, 3 and 5 still write unrefused, because doubling cannot produce an odd run. Without that control the fix would pass by refusing every backslash, which makes the payload route unusable for the regex and Windows-path cases the remedy explicitly sanctions. Both halves are asserted in the same fixture — a silence assertion passes when the harness is broken, so the odd arities are also the proof that the fixture can write a file at all.

  **The receipt names the run it found** rather than quoting a bare pair: the header reads `1 even backslash run`, each occurrence carries `-- a run of 4`, and the caret spans the whole run instead of its first two characters. A caret two wide under a run of four points at half of it, in a receipt whose only job is to say where to look. The remedy line generalised with it — `meant HALF the run` rather than `meant ONE backslash`.

  **Widening a refusal is the move that breaks correct callers, and it is only safe because the escape already existed.** `literal_backslashes = true` records the decision payload-wide and reaches the new arities; a run genuinely meant stays writable at every offset.

  **`old` keeps the note rather than gaining a refusal**, the adjacent gap the issue asked for a recorded decision on. It is an anchor: a doubled one cannot match, the runner reports the skip, and nothing reaches disk. But the note's reach is the scanner's, so it widened too — leaving `old` at two would have put the same blind spot one field over.
