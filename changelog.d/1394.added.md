- `replaces` entries take an `unless_flag`, so an op can declare which shapes of a command it does **not** supersede (#1394). `flag` and `value` only ever added specificity, so an op could say *this argv is mine* and not *this argv is mine except when it carries these flags* — and with the opt-out (`raw_command_guard: false`) repo-global, one over-broad entry disarmed every other mapping in the repository.
- `gl-api` is mapped on the strength of it (#1394): a plain `glab api PATH` read names the op, while `-X`/`-F`/`-f`/`--input` writes — which no supertool op answers at any spelling — stay usable, along with every other flagged shape down to `glab api -h`.
- An exclusion un-claims its own entry and never allows a command outright, a bare `--` ends the option list for the `flag` matcher too, and a malformed `unless_flag` drops the entry and reports `undecided` rather than reading as no exclusion (#1394).
