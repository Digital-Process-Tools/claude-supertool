- **`resolve_bin_cmd`'s backslash-to-slash normalisation no longer mangles a POSIX path that happens to contain a literal backslash** ([#2249](https://github.com/Digital-Process-Tools/claude-supertool/issues/2249)). The rewrite exists to keep an unquoted `\\Program Files\\` on Windows out of `shlex.split`'s escape handling (#2176), but it ran unconditionally on every platform — a `_BIN` env var such as `/opt/we\\ird/glab` (a legal POSIX filename) was silently resolved to the wrong, nonexistent `/opt/we/ird/glab`. The rewrite is now gated on `os.name == "nt"`.
