- **`changelog-fragment`'s assembler search had no repo-root bound.** `_find_assembler` walked `[target.parent, *target.parent.parents]` all the way to filesystem root looking for `assemble_changelog.py` (or one of the other `ASSEMBLER_LOCATIONS` names), then imported and *executed* whatever it found via `importlib.util.spec_from_file_location`. A fragment validated inside an untrusted checkout could pick up and run a same-named script sitting outside the repository entirely -- a sibling directory, or anywhere above it. `_find_assembler` now bounds the walk at the git repository root (`git -C <dir> rev-parse --show-toplevel`, the same convention `ci_lint_resolve_root.py` already uses), and a fragment validated outside any git repository refuses outright rather than falling back to the old unbounded walk.
