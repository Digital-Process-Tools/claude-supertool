- **Add a `classify` op**: a two-stage classifier for untrusted text, answering `safe` / `suspect` / `could-not-classify` ([#2046](https://github.com/Digital-Process-Tools/claude-supertool/issues/2046)). A deterministic scanner (`presets/classify/scanner.py`) names two near-zero-false-positive axes — `credential-shape` (reusing `presets/_secrets.py`) and `fence-forgery` (this repo's own fence glyphs, or a common chat-template marker) — and promotes to `suspect` on a match, never to `safe`. When the scanner finds nothing, a `claude -p` spawn with every tool denied (`--tools ""`, `--strict-mcp-config`, `--disable-slash-commands`) judges five fixed axes against the fenced text and must answer exactly `SAFE` or `SUSPECT: axis,axis`; anything else — prose, a timeout, a nonzero exit, an unparseable reply — is `could-not-classify`, which never renders as `safe`. `file://` only, no bare-path arm, matching the `#2039` precedent this op is built against. Standalone: callable by any op, a human, or the suite directly — no wiring into the Slack poller in this change.
