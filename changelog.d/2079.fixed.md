- **`registry:OP` now discloses a `builtin-ops` runtime override for a built-in op instead of refusing outright** ([#2079](https://github.com/Digital-Process-Tools/claude-supertool/issues/2079)). `_merge_presets` (#2025) writes a preset manifest's `builtin-ops` entries into the same merged config dict `_get_op_int`, `_get_op_bool` and `_grep_extensions` read for a built-in's runtime behaviour (`read.max_lines`, `grep.extensions`), so a preset — or a project's own top-level `builtin-ops` entry — could silently re-tune a built-in's behaviour project-wide with nothing in the tool disclosing it: `registry:read` refused unconditionally with `'read' is a built-in, not a preset or project op, so it has no registry entry`. `registry:OP` now checks the effective `builtin-ops.<op>` entry first and, when one exists, renders its runtime-affecting keys separately from its documentation-only ones (`syntax`, `description`, `example`, `status`, `hint`, `form` — the shape #1675 already ships for `vim`/`workspace`) and names which preset(s) contributed it. A built-in nobody's config re-tunes keeps the plain refusal unchanged. Two defects in the first draft were caught in self-review before commit and are fixed here: a `builtin-ops` KEY is preset-authored text as freely chosen as a value, and the render put it at the start of its own line while flattening only the value through `!r`, so a key holding a newline wrote a line of its author's choosing at column 0 inside system-authored output ([#1391](https://github.com/Digital-Process-Tools/claude-supertool/issues/1391)'s shape, one function over from the `_guard_quote` that already flattens field names for exactly this) -- the key now goes through `_flat_field` and is still shown, flattened, rather than dropped; and a `builtin-ops.<op>` set to a non-table (a malformed manifest, which `_merge_presets` stores without checking its shape and records no preset warning for) rendered byte-identical to no override at all, so that is now a stated third state naming the offending value instead of an absence the tool produced being read as an absence in the world.
