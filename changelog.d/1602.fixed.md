- `watch:gitlab-mr-feed` now announces an outage instead of going quiet ([#1602](https://github.com/Digital-Process-Tools/claude-supertool/issues/1602)). An unreachable GitLab, an expired token or a scope carrying an unknown filter token made the poller return an empty tick — alive, green in `watches`, and silent forever, which is exactly what a feed with nothing to report looks like. It now emits one `mrs_unreachable` per outage, carrying the reason and the last population size it could see, and keeps `known` so recovery does not re-announce every open MR as new. `radar` gains its own warning line and a `feed sight:` row under `radar:--state`, distinct from a poller that crashed, and a board whose feed cannot see no longer counts as healthy. `mrs_unreachable` ships in `DEFAULT_FEED_ONLY`.
