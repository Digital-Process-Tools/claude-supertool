- **`gh-issue-comment` refuses a `[[body]]` TOML table-array instead of publishing the literal Python `repr()` of the list as the comment body** ([#2322](https://github.com/Digital-Process-Tools/claude-supertool/issues/2322)). `_body_text()` did `str(payload.get("body") or "")`, which silently stringifies a list -- confirmed against a real posted comment on issue #2310 whose body read literally `[{'value': '...'}]`. Worse than a crash: the write succeeded and reported success while the published comment was garbage. #2315 made the same design decision for the sibling op `gh-issue-create`'s handling of this exact shape; applied here too, in both `validate()` (the real `main()` path) and `_body_text()` itself (for a direct caller). A non-string `body` is now refused with a message naming the accepted shape and pointing at `body_file`.
