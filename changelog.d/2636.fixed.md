- `_sanitize.py::wrap()` and each preset's own `read.py::render()` (youtube, bluesky, devto, hashnode) now flatten an injection-scan hit -- both a raw newline and a raw carriage return -- before joining it into the printed `POSSIBLE INJECTION` warning line. `detect()` returns the matched substring itself, and one of its own patterns (`(?:^|\n)\s*system\s*:`) can match across an embedded newline (with an optional carriage return right after it) in untrusted text -- unflattened, that put attacker-chosen text at the start of a second line, or moved the cursor back to column 0 of the current one, indistinguishable from a line the tool wrote itself. #2593 shipped the same one-line fix at one call site (`presets/youtube/status_since.py`, on the still-unmerged `fix/2593` branch / PR #2635); this closes the 8 remaining call sites across all 4 preset directories, including `presets/hashnode/read.py`, which the issue's own recon pass had not checked but carries the identical shape ([#2636](https://github.com/Digital-Process-Tools/claude-supertool/issues/2636)).
