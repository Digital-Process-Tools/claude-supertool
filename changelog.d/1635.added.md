- **A canary now watches whether a suite run leaves the tree standing.** #1635 recorded an unreproduced, once-observed event: a full `pytest` run in a fresh clone left the tree holding only `tests/` -- `.git` and everything else gone. `test_directory_removal_ownership_1635.py` (#1657) already proved every directory-removal call this tree's own Python makes is owned, which leaves the case that register cannot see -- a mechanism outside this tree's own code. `tests/conftest.py`'s new `pytest_sessionstart`/`pytest_sessionfinish` hooks (backed by `tests/_root_canary.py`) snapshot `.git`, `pyproject.toml` and `supertool.py` before a run and force the exit status red if any of them vanish by the time it ends -- silent on every ordinary green run, and named in `pytest_terminal_summary` only when it has something to say.
