- `which_excluding_cwd()`'s docstring (`validators/common/spawnable.py`, `presets/_spawnable.py`) overclaimed that any `name` with a directory component "carries none of" the cwd-shadowing risk. True only for an **absolute** component -- a relative one (`./bin`, `tools/x`) still resolves against cwd, which is deliberate and already config-gated (a validator's `env` may point at a relative binary path), not an oversight. Reworded to say so explicitly ([#2613](https://github.com/Digital-Process-Tools/claude-supertool/issues/2613)).
