- **A long-lived poller now says whether it is running the code it was forked with.** `watches` carries a new `VERSION` column -- `current`, `STALE`, or `unknown` -- built from a fingerprint each poller records at fork and compares against the source on disk at render time. A stale poller used to occupy its slot exactly like a current one, with `STARTED` the only clue, and nothing anywhere compared that timestamp against the code. `unknown` never renders as `current`: a poller nobody can prove is stale is not the same claim as one proven so. Report-only, the same discipline `DELIVERY` already carries -- nothing restarts a stale poller automatically. [#2179](https://github.com/Digital-Process-Tools/claude-supertool/issues/2179)
