- **A guard refusal whose remedy opens a real pull request** ([#1427](https://github.com/Digital-Process-Tools/claude-supertool/issues/1427)). `presets/github.json` claimed a bare `gh pr create` with no `unless_flag`, so `gh pr create --dry-run` — the flag whose whole meaning is *print details instead of creating the PR* — was refused and answered with `gh-pr-create:@FILE`, which opens one. That is the `misdirects` class: the named substitute performs the irreversible action the blocked command explicitly declined. #1427 closed the identical shape for `git push` and `git commit`; this is the instance it did not reach.
- **A `--help` is never replaced, by any op, in any registry.** Sweeping that class found it on all twenty-eight shipped mappings at once: `gh pr create --help` was blocked and told to open a pull request, `git push --help` was blocked and told to push. So `--help` and `-h` now un-claim every entry whatever it declares, rather than being a key each mapping has to remember — the direction #1394 was already pushed once, when `glab api -h` blocked with no way past was part of what justified the `*` spelling. Whole tokens only, deliberately unlike `unless_flag`: a short cluster is not expanded, or `-xh` would un-claim the whole repository, and `gh pr create -- --help` is still a file called `--help`.
