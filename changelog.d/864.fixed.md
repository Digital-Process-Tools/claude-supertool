- **`gh-issues` discarded a filter it did not recognise and printed the whole unfiltered board as the answer** ([#864](https://github.com/Digital-Process-Tools/claude-supertool/issues/864)). The argument parser kept a token if it was a known flag or parsed as a supported `key=value`, and let everything else fall off the end of the loop. So `gh-issues:nomilestone` returned every open issue, and a caller who asked which issues have no milestone was handed the exact opposite of the truth, in a render carrying no mark anywhere that the narrowing never happened. A typo'd filter key did the same: `milestne=v0.26.0` was dropped by the argv builder and the entire queue rendered as the contents of one milestone. Unknown tokens are now refused outright, naming each one and listing the filters and flags that would have been accepted.

  **This is the tracker's usual defect class with the sign flipped, and the flipped direction is the worse one.** The familiar shape is an absence produced by the tool read as an absence in the world — a checker reporting `ok` when it never ran. Here it is a failure to narrow read as a property of the world. An empty result invites suspicion; a full, plausible, richly-rendered board does not, which is why this survived a whole milestone-planning session unnoticed.

  **The `--limit` disclosure was measured against the survivors rather than against the fetch.** `--limit` bounds what came back from GitHub, so "more may exist" is a fact about the fetch. The footer compared its cap against the rows it was handed after `external` / `stale` filtering, so a filter that dropped rows below the limit also dropped the disclosure — from precisely the queries asking for completeness. It now compares against the fetched count.

  **The issue's own premise did not survive checking, and the report records why it looked true.** It was filed reporting that `milestone=` is not an accepted filter. It has been accepted since the op was born: `gh-issues:milestone=v0.26.0` has always reached `gh issue list --milestone`. What was missing was the advertisement — the `syntax` string in the preset manifest listed `author`, `label` and `state` and stopped, so the one place a caller checks before reaching for raw `gh` did not mention the filter that already worked. A capability nobody can discover is, from where the caller stands, absent. The syntax string now carries the full list.
