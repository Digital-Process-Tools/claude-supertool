- **`session_path()` now discloses when a session UUID resolved from a store that is not the caller's own** ([#1337](https://github.com/Digital-Process-Tools/claude-supertool/issues/1337)). Given a bare UUID it has always scanned every project store under `~/.claude/projects` and returned the first match — deliberate, and still correct, since a session id is globally unique. #1317 fixed the sibling substitution class for `resolve_project_dir()` (the store-resolution path used when no UUID is given) by walking upward only and declining sideways, and left `session_path()` unchanged on purpose: unlike that path, a cross-store scan hit here genuinely answers the caller's question, it just did not say which store answered. `session_path()` now returns `(path, note)`, and `tail.py`, `summary.py` and `cost.py` all print the note when it is non-empty — naming the store the session actually came from whenever it differs from the caller's own, so the substitution is disclosed rather than rendered identically to a same-store hit. A same-store hit, or no hit at all, still carries no note.
