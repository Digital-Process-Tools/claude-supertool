- **`gl-api` accepts a percent-encoded backslash in a filename** ([#1043](https://github.com/Digital-Process-Tools/claude-supertool/issues/1043)). `projects/1/repository/files/src%5Cmain.rs/raw?ref=main` was refused as a URL. `%5C` is a legal GitLab path segment and, since the files API takes the path percent-encoded, the only spelling available for a file committed from Windows as `src\main.rs` — so that file was unreachable through the op.

  The host check runs twice, once raw and once percent-decoded, and the backslash rule was travelling with the scheme and `//` rules on both passes. It is now raw-only in that flat form. The decoded pass does not simply drop it: dropping it would re-open `%5C%5Cevil.host/x`, which decodes to a pair of backslashes a WHATWG parser folds into `//evil.host/x` and which the `//` rule alone never sees. So on the decoded pass backslashes are folded into slashes and the two authority checks run on the result — a filename keeps its segment, an authority does not get to hide behind an encoder.
