- **The branch poller's "subscribes to every declared event" test now reads `sources/gh-branch/events.json` itself instead of comparing `BRANCH_ONLY` to a copy of `BRANCH_ONLY`** ([#2417](https://github.com/Digital-Process-Tools/claude-supertool/issues/2417)). `test_the_branch_poller_subscribes_to_every_declared_event` in `tests/test_watch_gh_prs_branch_poller_2024.py` asserted `set(branch_calls[0][2]) == set(tier.BRANCH_ONLY)` -- a tautology against itself, never against the source's own vocabulary, so a future event key added to `events.json` and never joined into `BRANCH_ONLY` would stay green while the poller silently stopped subscribing to it. The rewritten assertion reads the event keys straight out of `presets/watch/sources/gh-branch/events.json` and compares that set to `BRANCH_ONLY`; proven capable of catching the regression it exists to catch by temporarily dropping `went_failed` from `BRANCH_ONLY` and watching the test go red, then restoring it and watching it go green again.
