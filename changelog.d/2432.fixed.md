- **The mixed-tree decline's own suggested remedy no longer tells a write op to use `cwd:`** ([#2432](https://github.com/Digital-Process-Tools/claude-supertool/issues/2432)). `cwd:PATH` really does `os.chdir(PATH)` for the rest of the call, so following the old "Fix: run from {core}, or make the first op 'cwd:{core}'" advice for a write (`git-push`, `git-commit`, `gh-pr-merge`, `git-conflicts`, ...) silently pointed the write at the core checkout's own currently-checked-out branch instead of the worktree branch the caller meant — with no further decline, because the mismatch that triggered the decline is exactly what `cwd:` had just erased. `_mixed_tree_decline` now branches on the op's own safety class: a read-only op still gets the `cwd:` remedy (safe — it only needs the other tree's presets/config to answer), while anything else is told to run from inside the worktree with `python3 supertool.py` instead and is warned by name against using `cwd:` here.
