- **The even-backslash-run refusal on `paste`/`edit` now names `literal_backslashes` at the top of the message, before any occurrence is listed** ([#2314](https://github.com/Digital-Process-Tools/claude-supertool/issues/2314)). The refusal already carried a ready-to-paste `literal_backslashes = [...]` example, per-occurrence locations and an extension-keyed hint (#1794) toward whichever of its two fixes was the common case, but all three sat at the end of the message — a caller who had already hit this refusal on the same shape (prose documenting an escape sequence, not a doubling mistake) and knew they wanted the override still had to scroll past every located occurrence to find it, which cost the #2211 lane at least 4 resent payloads in one run. This is a message-clarity fix, not a narrower heuristic: the guard's own docstring already measured and rejected narrowing to "escape-looking" sequences (910/368801 tracked lines, 0.25%), because any escape set narrow enough to be a filter would miss the report it was written for. The fix changes only where the override is mentioned, never whether or when the refusal fires.
