- **The same `Program-Files`-splitting bug fixed for `GLAB_BIN`/`RUFF_BIN` in #2176 was still live in three more formatter adapters.** `formatters/phpcbf/phpcbf.py` (`PHPCBF_BIN`), `formatters/php-cs-fixer/php-cs-fixer.py` (`PHPCSFIXER_BIN`) and `formatters/prettier-write/prettier-write.py` (`PRETTIER_BIN`) each still ran the pre-fix idiom -- `shlex.split()` on the raw env var, unconditionally -- so a default Windows install under `C:\Program Files\...` split at the space, the adapter took the wrong first token as the binary, and reported `_BIN not found` for a path the operator never set. All three now go through the same `validators/common/bin_resolve.resolve_bin_cmd()` helper #2176 introduced, which tries the raw value as one whole path first and only falls back to `shlex.split` when that does not resolve to a real executable.
