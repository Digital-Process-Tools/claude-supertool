- **`strict_publish` fixture now isolates cwd, not only env** ([#1897](https://github.com/Digital-Process-Tools/claude-supertool/issues/1897)). `_publish_safety._supertool_config()` walks up from cwd to find `.supertool.json`, but the fixture only cleared the env-var opt-outs (`SUPERTOOL_PUBLISH_BODY_ALLOWLIST`, `SUPERTOOL_NO_PUBLISH_CONFIRM`) and never touched cwd, so two tests in `TestConfirmGate` read the checkout's own `.supertool.json` instead of an isolated one. That fires for any user whose repo config sets `no_publish_confirm` or `publish_body_allowlist`, whether or not this repo does. The fixture now `monkeypatch.chdir(tmp_path)`s as well, so every test using it is isolated by construction rather than by remembering to chdir per test.
