- The `PreToolUse` hook matched the `Bash` tool alone, so wherever the PowerShell tool is enabled every shell command bypassed the guard and the user saw nothing — which is exactly what a clean pass looks like. The matcher is now `Bash|PowerShell`, and a command routed through a shell this POSIX tokeniser cannot read is disclosed as undecided rather than decided: reading PowerShell quoting with `shlex` would produce false denies, whose only escape is repo-wide. The disclosure is limited to commands naming a binary some op supersedes, so it does not print under every call. ([#1413](https://github.com/Digital-Process-Tools/claude-supertool/issues/1413))
