- **`gl-api` declares a containment boundary for real, instead of being the grandfathered op the guard cited as declared** ([#1351](https://github.com/Digital-Process-Tools/claude-supertool/issues/1351)).

  `_syntax_names_a_path`'s docstring held `gl-api` up as the worked example of the safe pattern — "that op answers with `"paths": {"args": []}`, a declaration that someone made rather than a default nobody noticed". It carried no `paths` key and sat in `_UNDECLARED_PATH_OPS`, the grandfather register the same docstring describes emptying. The sentence the next author reads when deciding whether their op needs a declaration was pointing at an ungated one.

  Fixed by making the claim true rather than accurate: `gl-api:PATH` is an API route, it now declares `"paths": {"args": []}`, and the register shrinks from 20 to 19. The empty form carries no `root` — there is nothing for a boundary to bound, and inventing one would read as a choice somebody made.
