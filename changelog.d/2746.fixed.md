- **Upgrading across the rename to `supertool-cli` keeps working** ([#2746](https://github.com/Digital-Process-Tools/claude-supertool/issues/2746)). Found by the 0.66.0 release audit, each one exercised:
  - The session hooks now recognise a `./supertool` symlink into the plugin's former directory (`.../dpt-plugins/supertool/<version>/`) as their own and repoint it; before, they called it a stranger's file and every call kept running the old version. When the old version is gone, the hook says so and prints the `ln -sf` that fixes it.
  - A validator, formatter or mcp spec whose `NAME=value` block nothing reads (the key #2734 renamed to `variables`) is named on every call instead of dropped silently. `docs/mcp-integration.md` and `docs/validators.md` teach `variables`.
  - In the directory build, `git-push` no longer suggests `watch:...`, an op that build does not ship; `:watch` says why it cannot.
