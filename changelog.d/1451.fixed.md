- **`_checks.shortfall()` now flattens the leg names its callers hand it, instead of trusting that they already did** ([#1451](https://github.com/Digital-Process-Tools/claude-supertool/issues/1451)). It renders caller-supplied text and did not flatten it, so the [#851](https://github.com/Digital-Process-Tools/claude-supertool/issues/851) boundary held or did not depending on which caller you arrived through. The issue left open whether any caller outside `presets/github/branch.py` actually passes unreviewed text; three do. `gh-run` passes names read straight off the jobs API, `gh-pr` and `gh-pr-merge` pass names parsed out of a workflow file, and on one route the declined-count `reason` is built from a child process's stderr. Only `gh-branch` was flattening, and it was flattening at its own call site.

  The `reason` string is flattened too. `_untrusted.flat()` is idempotent, so the caller that already flattened pays a no-op rather than a second substitution — which is what makes the seam the right place for it rather than a rendering change.

  The comma is deliberately left alone here, unlike in `label()`: a matrix leg is routinely named `build (ubuntu-latest, 3.11)`, and substituting that separator would mangle real data to defend against nothing.
