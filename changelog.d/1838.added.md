- **`gh-pr-create` now refuses a body with no working closing reference, unless the payload says the omission is deliberate** ([#1838](https://github.com/Digital-Process-Tools/claude-supertool/issues/1838)). It used to report a missing `Closes #N` and open the PR anyway — measured across two sessions, four of seven agent-written payloads had no working reference, each repaired only because somebody happened to read the receipt. It now refuses before creating the PR unless `no_close = true` is set at the top level of the payload, which is the escape a `Part of #N` pull request needs: this repo's own merge gates protect that case by name, so the refusal stays openable rather than becoming a gate every payload template disables. `gh-pr-edit`'s own closing-reference gate is unchanged.
