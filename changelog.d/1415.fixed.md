- **The two `mode: block` jit rules that matched a substring anywhere in a command are pinned to command position** ([#1415](https://github.com/Digital-Process-Tools/claude-supertool/issues/1415)). `supertool-no-cut` and `gh-list-limit` were tested against the whole command text with no notion of where a shell would find a command word, so they refused **nine commands on 2026-08-11** that cut nothing and listed nothing — this repository's own directory name inside a `cd` path, a shell variable, a bar inside an op's own argument, and a quoted heredoc body four times, including the filing of the issue, the writing of its test file and the first attempt at this commit message. Both now open with `(^|[;&|\n])[[:space:]]*`, one character wider than the idiom `gh-pr-view-merge-have-ops.md` already used, because ` *` admits no tab and so misses a tab-indented continuation line.

  **Three narrowings, not one.** The cutting utility must now be a command word after the bar rather than any word after it, which is what stops a bar inside an op's own `grep:` argument; the scan is confined to a single line, which is what stops a heredoc body joining an earlier invocation; and the tool name must end at whitespace, which is what stops `supertoolkit` and `supertool-benchmark.sh`. One true positive is newly caught in exchange: a cut sitting behind a second pipe, which the old pattern let through.

  **Narrower is not precise, and the residue is named rather than left to be discovered.** A heredoc body line that *begins* with a command-shaped string still matches: only a tokeniser can tell a payload body from a command, and the jit matcher lives in `claude-jit-context`, a separate repository. `supertool-no-cut.md` says so in the rule text, so a reader who hits the next false positive meets the explanation rather than a rule that claims to be exact.

  The pin runs the real matcher: `tests/test_jit_block_match_anchored_1415.py` hands each live pattern to `awk` the way `pre-tool-hook.sh` does, asserts eight false-positive shapes go silent and eleven real invocations still fire, and fails on any future blocking row whose match is not anchored at all.
