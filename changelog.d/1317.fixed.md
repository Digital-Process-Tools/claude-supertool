- **`claude-log` answered with another directory's sessions when the cwd had none** ([#1317](https://github.com/Digital-Process-Tools/claude-supertool/issues/1317)). `project_dir()` fell back to the store whose encoded name shared the longest common *prefix* with the cwd's, and a prefix walks sideways. Measured from `~/Documents/st-wt/1317`, with 89 stores present and none of them this worktree's: it returned `-Users-floriandavid-Documents-st-wt-1024`, and `claude-log-list` and `claude-log-cost` rendered a normal, plausible board about a different worktree's work with nothing in the output naming the substitution. Worktrees are the normal shape here — nine were live the day it was filed — so this was the default state of a delegated run, not an edge case.

  Resolution is now **upward only**: the cwd's own store, else the nearest ancestor's, else nothing. A sibling is never an answer to "what happened in this directory". The resolver returns three states rather than a bare path — `direct`, `ancestor` and `missing` — because a `Path` cannot tell a hit from a substitution, which is the whole of the defect.

  `missing` declines by name, quoting the directory asked about, the store that would hold its sessions, and how many stores exist, so "none of them is yours" cannot be read as "there are none" and neither can be read as an empty board. `ancestor` is legitimate — a subdirectory belongs to its project — and is still not the directory the caller stood in, so it prints `Source: ancestor store — no sessions recorded for X; showing Y, which is not the same directory` rather than leaving the reader to diff a `Project:` path against their own cwd.

  Ancestors are derived from the path string, not from `pathlib`: on POSIX a backslash-separated Windows path is a single component with no parents, so a `.parents` walk would have resolved on Windows and declined on macOS for the same input.

  `claude-log-tail` and `claude-log-summary` take an explicit UUID and were never affected — `session_path()` identifies a session by name, not by neighbourhood.
