- **`git-status`'s `INCOMPLETE` footer could carry a forged line break from a timed-out `git diff --shortstat` call, one hop past the guard that already covered the `Target:` line** ([#1939](https://github.com/Digital-Process-Tools/claude-supertool/issues/1939)). `_git()`'s generic timeout path recorded `("git " + " ".join(args), res.stderr)` in `_UNANSWERED` unflattened, and one of its 17 call sites is the MR/PR shortstat diff, whose ref is built from the target branch exactly as the tracker reported it. A target branch carrying U+2028 or U+2029 — both accepted by `git check-ref-format` — forced that call to time out, and the raw separator reached the footer as an unaccounted line break in a receipt this repository parses. Flattened now at the one append `_git()` owns, so every one of its 17 call sites is covered by a single change rather than needing one apiece, and safe against a value that already went through `_untrusted.flat()` upstream because `flat()` is idempotent. Found by PR #1936's own self-review (#1933) and left there deliberately, as a change to a wrapper 17 call sites depend on that belongs on its own.
