- **README.md's lede said "One Python file, zero deps, Python 3.9+."** ([#2143](https://github.com/Digital-Process-Tools/claude-supertool/issues/2143)). True in April, false since `supertool.py` became a 171-line launcher over `_supertool.py` plus `presets/`, `validators/`, `formatters/` and `notifiers/` -- 1,000+ tracked Python files today. It now says "Stdlib only, zero deps, Python 3.9+" and names the actual launcher/core-module split, and `tests/test_readme_one_file_claim_2143.py` pins the retraction and the file-existence claim that replaced it -- not an exact file count, which would just move the drift into the test. A reviewer spawned on this fix found a second, adjacent stale number in the same file's "Design decisions" section ("`supertool.py` ... is ~80 lines" -- actually 171); that bullet is corrected too, and a test derives the number from `supertool.py`'s own line count rather than hardcoding it, so it cannot go stale silently a third time.
