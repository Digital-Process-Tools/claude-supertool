- **`gl-job:ID:artifact:PATH` now refuses a `..`/`.` segment instead of forwarding it into the `glab api` URL unmodified** ([#2230](https://github.com/Digital-Process-Tools/claude-supertool/issues/2230)). `urllib.parse.quote` never escapes `.`, so a traversal segment in the artifact path survived percent-encoding and reached `glab` verbatim, past the one guard (`presets/gitlab/api.py`'s `path_refusal`) this preset already has for exactly this question. `path_refusal` gained a `dot_segment_reason` check, and `_fetch_artifact_bytes` now runs the constructed URL through it before ever calling `glab` -- reused rather than a second hand-rolled check, and applied to the already-percent-encoded URL so the existing character allowlist stays meaningful.
