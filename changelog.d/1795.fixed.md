- **`yaml-check` and `actionlint` shipped, tested and dead in this repo's own config** ([#1795](https://github.com/Digital-Process-Tools/claude-supertool/issues/1795)). Both adapters existed, were registered in `.supertool.example.json`, and had never run on a single `.yml` edit in this checkout — `yaml-check` since it was written, `actionlint` since it landed in #1798. `.supertool.json` now registers both (`yaml-check` for `*.yml`, `yaml-check-yaml` for `*.yaml`, `actionlint` scoped to `.github/workflows/*.{yml,yaml}`), and a new guard, `tests/test_validator_registration_reachability_1795.py`, asserts every adapter under `validators/` is registered in at least one config and pins these two by name against this repo's real config so the same class does not ship a third time silently.
