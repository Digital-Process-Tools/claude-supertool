- **`gh-pr:N:diff:PATH` no longer promises hunks the byte cap withheld** ([#1078](https://github.com/Digital-Process-Tools/claude-supertool/issues/1078)). The `[same edit xN]` note ended `all hunks follow` unconditionally, one line above the `GH_PR_DIFF_MAX_BYTES` cap's own `this is NOT the whole file's diff` — two opposite claims in one render, with nothing saying which to believe. The cap is now measured before either sentence is written, and both take the result: an uncapped render still says `all hunks follow`, a capped one says the note covers every hunk parsed while the cap withheld part of the body.

  The multi-entry sentence (#1068) had the same shape and is fixed with it. Oldest-first assembly puts the current version of a twice-changed line at the bottom of the body, which is exactly what the cap removes, so it no longer points there in a truncated render.
