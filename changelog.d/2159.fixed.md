- **The four `formatters/*` adapters (`ruff-format`, `php-cs-fixer`, `prettier-write`, `phpcbf`) now route their `main` through `refusal.guard_main`, closing the crash net #1697 gave every validator** ([#2159](https://github.com/Digital-Process-Tools/claude-supertool/issues/2159)). An uncaught exception in any of the four used to write empty stdout with the traceback lost to a stderr the core never reads -- the exact #1697 failure, one directory over from where it was originally fixed. The three sweep tests that could not see this (`test_adapter_crash_net_1697.py`, `test_count_basis_contract_1728.py`, `test_adapter_duration_is_measured_1683.py`) now glob `formatters/*/*.py` alongside `validators/*/*.py`, each asserting its widened population is non-empty. Widening also caught two adjacent, pre-existing defects in the same four files: a `duration_ms` fabricated as a constant in three `except` arms per file rather than measured (#1683's own class), and none of the four declaring `count_basis`/`errors_truncated` -- fixed by measuring the clock in the first case, and by grandfathering the four (their `count` always equals `len(errors)` exactly, so there is nothing for the declaration to say) in the second.
