- **`presets/slack/_authorization.py`'s `load_project_config()` now warns on stderr when a project's `.supertool.json` is corrupt or malformed, instead of silently dropping every Slack channel to `off`** ([#2433](https://github.com/Digital-Process-Tools/claude-supertool/issues/2433)). Unparseable JSON and JSON that parses but is not an object at its top level both still return `{}` -- fail-closed is unchanged -- but now write a `WARNING: ...` diagnostic matching the sibling trust-violation branch eight lines above, which already warned. An absent config (nothing configured) stays silent, since that is not an error: `tests/test_slack_authorization_corrupt_config_diagnostic_2433.py` pairs each new warning case with a positive control that the absent-config and still-fails-closed behaviour did not change.
