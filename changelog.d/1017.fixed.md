- **The printed `supertool` invocation named `python3`, which is not the launcher on Windows** ([#1017](https://github.com/Digital-Process-Tools/claude-supertool/issues/1017)). `_git_common.st_hint` composes every copy-pasteable remedy these ops print, and its no-wrapper branch hard-coded `python3 supertool.py` in front of the op. On Windows the launcher is `py` or `python`, so the remedy handed to the reader most likely to paste it verbatim — mid-conflict, mid-failed-push — did not run at all.

  It now names `sys.executable`, the interpreter demonstrably running this code. That is the answer `_watch_argv` settled on for the spawn in [#642](https://github.com/Digital-Process-Tools/claude-supertool/issues/642), and the one `push.py::_st_hint`'s docstring already claimed the code used — the two disagreed, and the docstring pointed at the correct implementation while the code used the other one.
