- **A stalled git call no longer reads as "not inside a git repository"** ([#1858](https://github.com/Digital-Process-Tools/claude-supertool/issues/1858)). Seven ops open by asking `git rev-parse --git-dir` whether they are in a repository, and every one read a non-zero return as *no* — but `_git` returns `TIMEOUT_RC` (124) for a call that never answered, so a contended probe printed `ERROR: not inside a git repository.` about a repo that was mid-merge with live conflict markers. `git-conflicts`, `git-resolve`, `git-diff`, `git-commit`, `git-push` and `git-blame` now say they could not tell and why; `git-status` no longer drops its whole report on a stalled `branch -vv`; and `git-conflicts` stops reporting `no merge/rebase/cherry-pick in progress` for a state probe that did not answer. A directory that genuinely is not a repository is refused exactly as loudly as before — the failure path was the half most at risk from the fix.
