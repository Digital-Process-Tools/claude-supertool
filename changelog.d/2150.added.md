- **A session can now report how many channel events it actually received.** `channel:received:N` is #2051's unbuilt remedy 1: every counter this bridge publishes before now (`forwarded`, `dropped`, `lines_read`) is the forwarder describing its own outbox, and none of them can see the inbox. `received:N` compares a session's own self-reported count against `forwarded`'s advance over the same window and answers AGREE, DISAGREE by N, or UNSETTLED when no window could be diffed -- UNSETTLED never renders as AGREE, so a session that never calls this and one whose counts genuinely agree are not the same silence.
