- `grep` takes `all` in its LIMIT slot — `grep:PATTERN:PATH:all` — for the "find every one" question a capped result answers wrongly even when its `TRUNCATED, N matches total` marker is honest (#1328). The count line reads `limit all` and can never carry a truncation marker, so a completeness sweep cannot be read as a capped one. Works with context (`:all:2`), in `grep_around:PATTERN:PATH:N:all`, and as `limit = "all"` in a payload; refused in the CONTEXT slot, and never delegated to rtk, whose report cannot count what it did not collect.
