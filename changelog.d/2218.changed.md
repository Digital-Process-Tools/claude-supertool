- **CI's Windows leg excludes the checkout and runner temp directory from Windows Defender scanning** (#2218). Defender's real-time scanner walking every small temp file the suites create per assertion is a documented `windows-latest`-specific cost neither macOS nor Linux carries. `Add-MpPreference -ExclusionPath` on the checkout and `$RUNNER_TEMP`, Windows-only, before the test step. No suite is touched, disk I/O overhead removal only. Ported from Digital-Process-Tools/claude-jit-context#310.
