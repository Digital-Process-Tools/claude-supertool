- **The plugin manifest carries its directory listing** ([#2736](https://github.com/Digital-Process-Tools/claude-supertool/issues/2736)). `.claude-plugin/plugin.json` gains `displayName` ("Supertool CLI"), `homepage`, `documentationUrl`, `supportUrl`, `privacyPolicyUrl` and `termsOfServiceUrl`, and the plugin ships an icon at `.claude-plugin/icon.png` (1024x1024, opaque, rendered from `docs/icon.svg`). The Anthropic directory reads all of these from the branch it validates and takes the icon once, at the first save, so they have to be in the tree before the submission. `PRIVACY.md` is new, written from the code, and read on GitHub through its URL: the release tree denies it.
