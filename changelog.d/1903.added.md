- **`SUPERTOOL_GIT_TIMEOUT`'s three defaults are now guarded against the prose that documents them** ([#1903](https://github.com/Digital-Process-Tools/claude-supertool/issues/1903)). #1886 fixed `docs/validators.md` and `validators/git-status/README.md` to state all three defaults (5s in `presets/git/status.py`, 10s in `presets/git/_git_common.py`, 15s in the `git-status` validator) instead of one — but nothing joined that prose to the code, so the next time any of the three numbers moved, the docs would go stale silently again. `tests/test_git_timeout_defaults_agree_1903.py` imports each module's own constant and regex-extracts each doc site's claimed number, failing loudly when a default moves without its prose, when a doc site's wording no longer matches the extractor, or when either doc site claims a fourth site the test does not know about. Same shape as `.oss.json`'s `version_sites` / `test_version_sites_agree_1854.py`, one variable over.
