- **Documented the two hints inside the even-backslash-run refusal, and when the guard does not fire at all** ([#2327](https://github.com/Digital-Process-Tools/claude-supertool/issues/2327)). `docs/operations/edits.md` and `docs/input-forms.md` explained the refusal's shape but predated #2314's opening-sentence pointer to `literal_backslashes` and #1794's extension-keyed hint (`.py`/`.json`/... toward the override, `.md`/`.txt`/... toward halving the run) — neither doc mentioned either. Reproduction also showed the scenario that prompted this issue does not actually trip the guard: a single un-doubled `\n` inside a Python string literal is an ODD run, which the guard has never flagged, so both docs now say so explicitly rather than leaving a reader to worry a legitimate escape sequence will be refused. No jit-context rule was added — the refusal message is now itself the just-in-time context, surfacing the fix at the moment it is needed.
