- **Every Slack poller on a host no longer shares one 500-file message-body eviction pool.** Each watched channel now gets its own `slack-messages/<channel>/` subdirectory, each with its own cap, so a burst on a busy channel can no longer evict a quiet channel's older files before an agent has opened them -- a real loss since #2044 moved message bodies to `payload_path`, where an evicted file and one never written were indistinguishable.
