- **Bluesky session cache is no longer world-readable between write and chmod** ([#2484](https://github.com/Digital-Process-Tools/claude-supertool/issues/2484)). Both `presets/bluesky/_atproto.py::_save_session` and `presets/watch/sources/bluesky-engagement/poller.py::_save_session` wrote the `accessJwt`/`refreshJwt` session cache with `write_text()` and only narrowed it to `0o600` in a *separate* `chmod()` call afterward, leaving the file briefly at the process umask (measured `0o644`, world-readable, on the reporting host) in between. Both now create the file via `os.open(..., os.O_CREAT | os.O_TRUNC, 0o600)`, so it is `0o600` from the instant it exists on disk, and `os.fchmod` narrows a pre-existing file left wide by the old code.
