- **`watches` no longer reports an empty fleet while pollers it can see are running** ([#1881](https://github.com/Digital-Process-Tools/claude-supertool/issues/1881)). A machine reached load average 409 with 564 orphaned `dispatcher.py poll` processes live across five slots, and the board printed `No active watchers. None recorded as lost either.` The process scan had run, had succeeded, and had seen all 564 — they were another channel's, so `scan_poller_pids` dropped them and the render then denied they existed. That left the operator with no documented route to them at all: `watches` showed nothing and `unwatch:SOURCE:ID` had no slot to name, so the only tool that worked was the `pkill` this preset tells operators not to use.

  The scan keeps its contract — `scan_poller_pids` still answers with this channel's pollers alone, because every caller of it decides an *action* and widening it would restore the cross-channel kill [#1514](https://github.com/Digital-Process-Tools/claude-supertool/issues/1514) was filed for. What that issue settled was which pollers may be listed as rows and signalled; it did not settle whether their existence may be stated, and the render took the stronger reading. `transport.poller_census` now returns all three of the label's answers, and `watches` discloses the two it may not act on as **counts, never rows** — no SOURCE or ID is printed, because naming one is what invites `unwatch` against a slot this channel does not own.

  The channel token is a digest of the state directory and cannot be reversed, so a bare `chan=43b6d3f23b71` is not something an operator can act on. The sibling directories are hashed forward instead, which names the state directory — and so the `SUPERTOOL_WATCH_NAME` whose own board can stop those pollers. Three states, as everywhere else here: a directory that matches, no directory that matches, and a base directory that could not be listed. When the scan itself did not run, no count is printed at all; `0 pollers on another channel` read off a scan that never happened is the same substitution one layer in.

  The unqualified sentence survives for the genuinely clean case. When pollers were counted above it, the board says `No watchers on this channel` — disclosing 564 processes and denying them in consecutive lines is the defect rendered twice.
