- **`watch_sources_path` accepts a relative entry declared in `.supertool.json`** ([#2164](https://github.com/Digital-Process-Tools/claude-supertool/issues/2164)). `presets/watch/sourcepath.resolve()` refused any entry that failed `os.path.isabs()`, with no `expanduser`/`expandvars`, so a shared `.supertool.json` could only carry the key by committing one developer's home directory. A relative entry is now resolved against the directory of the `.supertool.json` that declared it, at the one place a `watch_sources_path` config key turns into `SUPERTOOL_WATCH_SOURCES_PATH`, before the op's subprocess — and everything a poller re-execs into — ever starts, so what a detached, re-exec'd poller inherits and re-derives is already an absolute path. An entry that arrives straight through the environment, with no declaring config file, keeps today's absolute-only rule.
