- **`git-resolve`'s duplicate-heading guard now sees a setext heading (`Title` underlined with `===`/`---`), not only `## Title` (ATX)** ([#1123](https://github.com/Digital-Process-Tools/claude-supertool/issues/1123)). `_heading_paths` was blind to the setext style entirely, so a `both` union that duplicated a setext-styled section heading was staged and reported clean -- #911 unfixed for that spelling. It now reads one line of lookback: an underline only means "the line above it is a title" when that line is real, unconsumed text, so an ordinary thematic break (`---` after a blank line, or two underline lines in a row) is never misread as a heading.
