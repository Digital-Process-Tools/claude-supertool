- **A non-numeric `ts` from Slack could raise `ValueError` out of the `slack` watch source's `poll()` and kill the watcher**, where every other failure arm honours `_fetch`'s own never-raise contract and returns `(None, why)` instead ([#2063](https://github.com/Digital-Process-Tools/claude-supertool/issues/2063)). The `float(ts)` conversions inside `_fetch`'s sort/filter keys and `_anchor`'s cold-start `max()` now go through a guard that reports and keeps the poller alive on a value it cannot parse, the same way an unreachable Slack or a revoked token already does. Reachability was not demonstrated at filing -- Slack's own API does not return a non-numeric `ts` -- so this closes the one path that broke the stated contract, not a route known to reach it.
