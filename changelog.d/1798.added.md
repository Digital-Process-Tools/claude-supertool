- **An `actionlint` validator for `.github/workflows/*.{yml,yaml}`** ([#1798](https://github.com/Digital-Process-Tools/claude-supertool/issues/1798)). Nothing checked whether GitHub would accept this repo's own workflow files or whether a job did what it says — two hand-rolled greps (`test_coverage_gate_workdir_877.py`, `test_ci_job_timeouts_722.py`) stood in for that as a schema check, which is the shape of a missing validator. The new adapter wraps `actionlint -no-color -oneline`, mapping its `file:line:col: message [rule]` output onto the shared error shape the other adapters emit. `actionlint` is not installed on the machine this was written on, so the absent-tool path was written and tested first: `skipped` with an install hint (`brew install actionlint`), never a fabricated `ok: true` about a workflow nothing checked — the same failure #1202 fixed across ten other adapters, and now pinned generally for this one too via `tests/test_validators_absent_tool_third_state_1202.py`. Registered in `.supertool.example.json`; the intentionally-hard `glab ci lint` half stays out, split off as #1797.
