- **The forged-child-stream census miscounted a boolean comparison as a raw
  relay** ([#1637](https://github.com/Digital-Process-Tools/claude-supertool/issues/1637)).
  `presets/github/check.py`'s `absent=(kind == "notfound")` scored one raw
  `stderr` relay even though the comparison it builds always produces a fresh
  `bool` — nothing about the tainted operand's text reaches the `return` through
  it. The census's own taint model (`tests/test_forged_child_stream_line_1475.py`)
  now treats `ast.Compare` the way it already treats `IfExp.test`: a
  comparison's operands feed the comparison, never the value that flows onward.
  Measured before the rule was added: it moves the census 139 -> 138 sites
  (`check.py`'s one site, the only one anywhere in `presets/git`,
  `presets/github` or `presets/gitlab` shaped this way) and leaves `UNRESOLVED`
  unchanged.
