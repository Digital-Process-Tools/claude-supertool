- **`git-status`'s MR/PR diff line no longer collapses a `git diff --shortstat` timeout, an unfetched target ref, an unreported target branch, or any other local git failure into the same silent render as a genuinely empty diff** ([#1933](https://github.com/Digital-Process-Tools/claude-supertool/issues/1933)). The line's `changes_count` guard already proves the diff is non-empty before the local shortstat runs, so a bare `Diff: N files` inside that branch could only mean the call did not answer — never that there was nothing to count. A clean result still prints `(+a -d)`; a failed one now prints `` (+? -? — `git diff --shortstat` did not answer: <reason>) `` right on the same line. An unfetched target ref stays out of the `INCOMPLETE` footer deliberately — it is the ordinary case on a shallow or partial checkout — while a genuine timeout still reaches the footer, unchanged, because `_git` itself records that unconditionally.
