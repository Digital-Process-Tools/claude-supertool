- **`git-status`'s MR/PR diff line no longer collapses a timeout, an unfetched target ref, or any other `git diff --shortstat` failure into the same silent render as a genuinely empty diff** ([#1933](https://github.com/Digital-Process-Tools/claude-supertool/issues/1933)). The line's `changes_count` guard already proves the diff is non-empty before the local shortstat runs, so a bare `Diff: N files` inside that branch could only mean the call did not answer — never that there was nothing to count. A clean result still prints `(+a -d)`; a failed one now prints `(+? -? — 'git diff --shortstat' did not answer: <reason>)` and, when it isn't a timeout, is also recorded for the `INCOMPLETE` footer. A timeout was already recorded there but the diff line itself stayed silent, which matters for a caller reading `:brief` or truncating at the top.
