- **`duration_report.py`'s per-suite parse comment claimed the opposite of what the code does, and a partial parse was never disclosed** ([#2274](https://github.com/Digital-Process-Tools/claude-supertool/issues/2274)). The `except (TypeError, ValueError): continue` inside `parse_junit`'s `for suite in suites:` loop advances the *suite* loop, so a suite whose own `<testsuite time=...>` is missing or unparseable also skips every `<testcase>` beneath it — the comment on that line said the testcases "below are not" unusable, which is false. `parse_junit` now returns which suite(s) were dropped, and `render()` prints a fourth, disclosed state, `partial-parse`, naming them, rather than silently printing `(NN.NN% of total)` against a total that is short one suite's seconds — the same "empty top-N list read as no hot test" defect this module already guards against one level up.
