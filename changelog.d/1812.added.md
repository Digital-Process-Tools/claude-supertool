- **A test can now ask for a preset-derived op instead of rediscovering why it is missing** ([#1812](https://github.com/Digital-Process-Tools/claude-supertool/issues/1812)). `tests/conftest.py`s autouse `_disable_rtk_and_config` hands every test `_CONFIG = {}` — deliberately, because `_load_config()` walks up from the cwd and an unreset config would make a test behave differently depending on which checkout it ran from. The cost was that every op routed through a preset manifest rather than the builtin table did not exist in any test: `git-commit`, `git-push`, the whole `gh-*` family, never intermittently and never only locally.

  `with_preset_op(*names, payload_route=False)` is the opt-in. It reads the entries off the shipped manifests through the real loader, installs only the ops named, and returns them. **It fails rather than skips**, in all three refusals: no shipped config declares the name, the entry declares a payload route in its `syntax` that derives no field names ([#770](https://github.com/Digital-Process-Tools/claude-supertool/issues/770)), or a route was demanded of an op that has none. A preset manifest that cannot answer is a broken checkout, not an under-equipped machine — so there is no environment in which a skip would be the honest answer, and a fixture that skipped would reproduce one layer up the defect it exists to remove.

  On [#1776](https://github.com/Digital-Process-Tools/claude-supertool/issues/1776) a test asserting that the `@-` guard refuses `git-commit` — the most destructive op the guard covers — armed a skip on the absent route and took it on every invocation, reporting `git-commit has no payload route in this environment`. A well-written message that reads as a local quirk, for an assertion that had never executed anywhere. That fixture is now three lines over `with_preset_op`, and the argument is made once for the suite rather than per file.

  A census over the whole suite says how big this was: **0 of 90 skips in a full run are attributable to the reset**, and no surviving assertion was found covering nothing because of it — a papercut on that axis, which is the answer the issue asked for and did not assume. What the census did find is duplication: **43 test files carry a hand-rolled opt-out**, in three distinct idioms, each rediscovering the mechanism from scratch.
