- **Decided against a dedicated `agent-note:*` op family for sub-agent findings, and documented the recipe that replaces it** ([#1497](https://github.com/Digital-Process-Tools/claude-supertool/issues/1497)). The issue asked for a place to put a sub-agent's findings, a stable id, and a listing so a later turn can find a note it did not create. All three are already answered without new code: `paste` writes the note, the path is the id, `glob` lists a directory of them, and `read:PATH:::grep=PATTERN` filters one down — the exact query the issue's own examples describe. The issue's own follow-up comment measured this on a real delegation and found the query side "never even fired," which is the reasoning against building it now rather than an untested guess. README's "Beyond the ops table" section carries the recipe.
