- **A `shellcheck` validator — shell semantics, where `bash -n` only ever answered "does this parse"** ([#665](https://github.com/Digital-Process-Tools/claude-supertool/issues/665)). `shellcheck -f json`, ruleset resolved from the project's own `.shellcheckrc`, `rollback_on_fail: false`. `bash-check` stays: it is in-process-cheap and it is what still runs where shellcheck is not installed. An absent `shellcheck` reports `skipped` with the install hint, never `ok`.

  **The receipt in the issue does not hold, and the docs now say so.** #665 justifies the validator with `claude-remember#251` and calls it "SC2015 verbatim". Measured against ShellCheck 0.11.0, SC2015 does not fire on that line at any severity, with every optional check enabled — the rule carries a deliberate carve-out for an `|| echo`/`|| printf` branch, and the redirect on that `echo` is what made the bug destructive. So this validator would not have caught the bug it was filed for. `tests/test_validators_shellcheck_665.py::test_the_issues_own_receipt_is_not_caught` pins the gap, so a future ShellCheck that closes the carve-out fails the test and corrects the documentation in the same pull request.

  What does fire, and is exercised on real files rather than assumed: SC2164 (`cd` without `|| exit`), SC2086 (unquoted expansion), SC2181 (`$?` instead of testing directly) and SC2155 (`local x=$(cmd)` masking an exit code).

- **`SUPERTOOL_REQUIRE_VALIDATORS` — a skip that CI can refuse to accept** ([#665](https://github.com/Digital-Process-Tools/claude-supertool/issues/665)). The three new validators all wrap external binaries most machines lack, and `skipped` on every run of every job is how a validator becomes decorative. Naming one in this variable turns "the tool is not installed" from a third state into a loud `adapter` error whose message names the variable, so the reader is sent to the CI image rather than to the file. Comma- or `os.pathsep`-separated, case-insensitive, `*` for all. It only ever turns quiet into loud — there is deliberately no value that turns a finding into a skip.
