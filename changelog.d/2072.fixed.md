- **`changelog-fragment` searches known assembler locations instead of one hardcoded path, and no longer reports a failed lookup as a fact about the project** ([#2072](https://github.com/Digital-Process-Tools/claude-supertool/issues/2072)). The adapter only ever tried `.github/scripts/assemble_changelog.py`; `/oss:scaffold` writes `.oss/assemble_changelog.py` or `scripts/assemble_changelog.py`, so every repository that plugin sets up landed in `skipped` by construction and read "this project does not declare changelog fragment rules" -- a claim about the project the adapter never checked. `ASSEMBLER_LOCATIONS` now tries all three, in order, before giving up, and the `skipped` message names every location it tried instead of asserting an absence in the world. `SUPERTOOL_CHANGELOG_ASSEMBLER` still overrides with one exact path for anything else.
