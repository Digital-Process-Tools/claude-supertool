- **`gl-issue-create`/`gh-issue-create` refuse a `labels` field that is not an array** ([#2173](https://github.com/Digital-Process-Tools/claude-supertool/issues/2173)). A comma-separated string (`labels = "A,B,C"`) used to be iterated character by character, sending one `--label` flag per character to `glab`/`gh` and silently creating one throwaway label per distinct character -- 30 junk labels on a sibling tracker before anyone noticed. Both ops now refuse before any `glab`/`gh` call when `labels` is present but is not a list of non-empty strings.
