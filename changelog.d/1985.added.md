- Added `oss-tick`, a new shipped preset (`presets/oss`). It composes the mechanical opening of the `claude-oss` maintainer tick -- last state entry, pending wait, plugin identity vs last recorded, `git fetch && git pull --ff-only`, the board (gh-prs/gh-issues/gh-branch/git-worktrees) and radar tier resolution -- into one round-trip receipt whose every row is one of three states, never two. It is a thin shim: it locates the installed `oss` plugin from Claude Code's own install record and execs that plugin's own `oss_state.py`, so no maintainer-loop judgment lives in this repository.
