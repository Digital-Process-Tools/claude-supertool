- **`ci_lint_resolve_root.py`'s empty stdout meant four different things.** `_repo_root` returned `None` -- and `main()` printed nothing -- for three "could not look" cases (`git` absent, `git` timed out, the target is not inside a git repository) and for the one legitimate "looked, and this repo genuinely has no root `.gitlab-ci.yml`" case, all identically. Downstream, `_validator_resolve` and `_validator_run_one` (`_supertool.py`) turned every one of the four into the same `{"skipped": "no target resolved"}`, so "this repo has no GitLab CI" and "I could not even look" were indistinguishable -- this repo's own named defect class: an absence produced by the tool, read as an absence in the world. `_repo_root` now returns a reason alongside `None` for the three "could not look" cases, and `main()` prints a `RESOLVE-ERROR: <reason>` line instead of nothing; `_validator_resolve` recognizes that shared protocol and `_validator_run_one` renders it as a distinct skip reason, leaving the genuine "no root config" case's empty stdout untouched.
