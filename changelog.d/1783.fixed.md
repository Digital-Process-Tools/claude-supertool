- **`help:OP` on a pip install no longer prints a false "incomplete install" sentence about a route the README endorses** ([#1783](https://github.com/Digital-Process-Tools/claude-supertool/issues/1783)). `pip install .` (`py-modules = ["supertool", "_supertool"]`, no packages, no `MANIFEST.in`) ships neither `.supertool.json` nor `presets/`, so `_shipped_config()` found nothing for any op the project's own config does not document. Every declarative packaging route that could carry a data file there was tried and rejected -- `package-data` globs over declared *packages* and a flat `py-modules` layout has none; `MANIFEST.in` + `include-package-data` reaches the sdist, never the wheel; `data-files` lands in the venv prefix, not site-packages. The fix ships `_shipped_reference.py` instead: a plain module in `py-modules`, generated by `.github/scripts/generate_shipped_reference.py` from this repo's own `.supertool.json`, carrying only the `builtin-ops` block -- never the `ops` section, which documents preset-config overrides for `presets/` this route does not ship. `_shipped_config()` falls back to it, loaded by path from beside the running `_supertool.py`, only when `.supertool.json` itself is absent there; the clone and plugin routes are unchanged.
- **The same lookup no longer conflates an unreadable install *directory* with a genuinely absent one.** `os.path.exists()` swallows `EACCES` and returns `False` for a directory the process cannot traverse, so a reference sitting inside a `chmod 000` directory reported "is not there" -- the exact false sentence #1781 removed one file down, one level up. The pre-check is gone; `_shipped_config()` now opens unconditionally and branches on `FileNotFoundError` (genuinely absent) versus any other `OSError` (unreadable).
- **The `help:OP` refusal's final `else` arm no longer asserts a specific, false claim about a verdict it has never seen.** It caught `"read"` and any future fourth value alike and said "was read and does not document it either" about both. `"read"` is now an explicit `elif`; the real `else` reports the verdict as unknown instead.
