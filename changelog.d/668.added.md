- **A `gitleaks` secret-scanning validator — thirty validators and none of them looked for a credential** ([#668](https://github.com/Digital-Process-Tools/claude-supertool/issues/668)). `gitleaks detect --no-git --redact` on the edited file, no `match` glob because a credential is not a property of a file type. This is the one check whose absence is a disclosure problem rather than a quality one: a pushed secret is a rotated secret.

  **The finding never carries the value, and neither does anything written on the way to it.** gitleaks' report holds the secret in cleartext and `--report-path` is the only route to JSON, so the naive adapter writes the credential to disk before deciding not to print it. Three layers: `--redact`, so the value never reaches the report; a `mkdtemp` at mode `0700` removed in a `finally`, so no report survives a crash; and no `source_context` on the error, because the source line *is* the secret and a validator receipt is a terminal, a log and an agent transcript at once. The rule id, line and description are what a reader needs to act. `tests/test_validators_gitleaks_668.py` asserts this against the whole serialised payload, so a future field cannot reintroduce it quietly.

  **`rollback_on_fail` is `false`, against the issue's own suggestion.** Reverting does not unpublish anything — the value reached the edit from a payload, a paste or a context window, all of which still hold it — while it does destroy everything else the edit contained. And a `--no-git` scan of this repository returns 12 findings of which 12 are test fixtures, so rollback would have reverted real work over fake keys, which is the fastest route to the validator being switched off. The finding stays fully loud; only the destructive auto-revert is off.

  **False positives are suppressed per line, never per directory.** A trailing `gitleaks:allow` comment is one line, lands in the diff and says nothing about the next line. The lever deliberately not shipped is an `exclude` glob over `tests/` or `docs/`: it turns the check off invisibly and permanently for exactly the paths most likely to grow a real credential, and a silenced scanner looks identical to one finding nothing. A test pins the absence of that glob.
