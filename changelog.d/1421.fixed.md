- **`CLAUDE.md` no longer claims the raw-command guard cannot see `git -C <path> <sub>`** ([#1421](https://github.com/Digital-Process-Tools/claude-supertool/issues/1421)). The line dated from when `argv` matching was a contiguous token prefix; measured on 2026-08-15, `supertool 'guard:git -C /tmp/x commit -m y'` answers `BLOCKED` and names `git-commit`. A stale line about a *missing* capability is the shape this repository's own notes warn about hardest, because it suppresses the one call that would disprove it.
