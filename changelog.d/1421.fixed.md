- The raw-command guard could not see past a program's own global options, so `git -C /tmp/x status` answered `OK: nothing in this command is replaced` while plain `git status` was blocked — one subcommand, two verdicts, and the clean one byte-identical to a command nothing maps. Global options are now normalised away from a per-command table before scoring, and a pre-subcommand option that table has no grammar for is `UNDECIDED` rather than a guess: guessing an option's arity swallows the subcommand, and the resulting wrong block has no per-command escape. Not git-only — `glab --repo O/R mr view 1` was affected too; `gh` was not, because it rejects a pre-subcommand `--repo` outright. ([#1421](https://github.com/Digital-Process-Tools/claude-supertool/issues/1421))
