- **`doctor`'s `## Formatters` section now WARNs when `.supertool.json` carries no `formatters` key at all, and reports `ok` for an explicit `"formatters": {}`** ([#2316](https://github.com/Digital-Process-Tools/claude-supertool/issues/2316)). The bare bullet used to sit weighted identically to a genuine `not applicable` line ("no tracked file matches"), but the two facts are not the same: "no formatter configured" means a capability is switched off and every write goes out unformatted with nothing saying so, while "not applicable" means there is nothing for the check to do. `doctor` now reads three states rather than two — an absent `formatters` key is a WARN, an explicit empty dict is `ok` (a decision on record), and a populated one is reported per-formatter exactly as before — the same absent-vs-empty shape `claude-oss`'s own `changelog_untagged` config key already uses.
