- **A directory install no longer starts every session with "unknown operation: channel"** ([#2734](https://github.com/Digital-Process-Tools/claude-supertool/issues/2734)). The directory build drops `presets/watch.json`, where `channel` is declared, but `hooks/session_start.py` still asked for `channel:stranded` after the op listing, so each session opened on an error and the full list of valid operations. The hook now asks only when the plugin ships `presets/watch.json`.
