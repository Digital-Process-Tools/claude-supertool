- **The #1206 shim gate read the quoting instead of the defect** ([#1419](https://github.com/Digital-Process-Tools/claude-supertool/issues/1419)). `tests/test_git_shim_subcommand_1206.py` scans the suite for shell shims that decide a git subcommand from `$1` — the defect being that git's global flags precede the subcommand, so `git -C <path> status` puts `status` in `$2` and the shim silently stops standing in. The scan was anchored on `"[$]1"`, which matches `$1` only inside double quotes, so `[ $1 = status ]` and `[ '$1' = 'status' ]` were the same defect and invisible to it. A meta-test whose zero means "nobody in this suite has this bug" was reading one spelling of three — the house defect, relocated into the detector — and self-corroborating, because every shim it has ever caught was written in the style it reads.
- The gate is now quoting-blind: quotes are stripped before the grammar is applied, so double-quoted, single-quoted, bare and `${1}` spellings are one rule rather than one rule each, and a style nobody has invented yet arrives already handled. It also reads `[[ ... ]]`, `test ... = ...`, `case $1 in`, the `[ x$1 = xstatus ]` idiom that guards an unset `$1`, and a comparison written backwards as `[ status = $1 ]` (#1419).
- Widening the match alone would have been wrong. The question the gate asks is whether `$1` is *tested*, not whether it appears, so it now keys on the shell constructs that decide on a word. Six literals in the suite hold a bare `$1` that decides nothing — three `awk '{print $1}'` field references and three shellcheck fixtures spelled `rm $1` — and a match widened to any occurrence turns all six red; a gate that cries wolf gets its allowlist grown until it means nothing (#1419).
- What the widened scan actually found across the 696 modules it reads (698 `test_*.py`, less itself and the one filename exemption): five literals test `$1`, four of them exempt because the operand is an option (`-3`, `-c`) and git's grammar leaves an option no position to slide to, one the pre-existing `test_watch_mine_defaults.py` exemption where `$1` really is a supertool op. **Zero new defects.** The judgement half [#1412](https://github.com/Digital-Process-Tools/claude-supertool/pull/1412) derived from git's grammar holds under the wider match, and the three original #1206 shims are still caught verbatim (#1419).
