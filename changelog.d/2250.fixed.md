- **`resolve_bin_cmd`'s "not found" diagnostic now names the configured value, not just its `shlex.split` fragment** ([#2250](https://github.com/Digital-Process-Tools/claude-supertool/issues/2250)). When the whole-path existence check fails, the fallback split can change the value's shape -- an unquoted Windows install path like `C:\\Program Files\\glab\\glab.exe` used to split into `["C:/Program", "Files/glab/glab.exe"]`, and the error a caller (`phpcbf`, `ruff-format`, `php-cs-fixer`, `prettier-write`, `ci-lint`'s `glab`) reported named only `C:/Program` -- a path the operator never configured. `describe_unresolved()` now appends the original raw value alongside the split fragment whenever the two differ, so an operator can tell a typo from a genuine multi-token command.
