- `cargo-check` charged another crate's compile error to the file under
  validation, which on a `rollback_on_fail` validator reverted a correct edit
  over a defect it never touched. The path-suffix match #754 introduced had no
  floor: a one-segment target matched any file of that basename anywhere in the
  tree, and the raw `{file}` argument was compared in whatever relative form the
  caller typed, so `vendor/crates/foo/src/main.rs` and `crates/foo/src/main.rs`
  were "the same file". A suffix now has to be at least two segments, and every
  form of the target is anchored to the working directory before comparison.
  cargo's own path stays a free tail — it is relative to the workspace root, and
  joining it onto the crate root is the demotion #754 exists to prevent.
