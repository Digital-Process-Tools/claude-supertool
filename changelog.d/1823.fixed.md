- **A radar tier that could not reach the forge no longer reports it as a missing credential, and no longer prints a remedy for a cause it did not establish** ([#1823](https://github.com/Digital-Process-Tools/claude-supertool/issues/1823)). `radar` failed with `RadarUnreachable: gh not authenticated. Run: gh auth login` between two successful authenticated `gh` calls seconds apart. `gh auth status` immediately after reported the same account and the same scopes the surrounding calls had used, and a bare re-run with nothing changed passed. The message named a cause that was false and the remedy it printed would have been a no-op.

  **The predicate was one bare substring.** Both tiers asked "is this an auth failure?" with `if "not logged in" in err.lower() or "401" in err`, and `"401" in err` tests three characters against the whole of a CLI's stderr. GitHub writes those three characters into a user id (`API rate limit exceeded for user ID 44012345`), into a request id (`[request-id: C401:1F2A:9B3D]`), into an epoch and into a byte count; GitLab writes them into a correlation id. Each of those is a failure that says nothing whatever about the credential, and each of them rendered as the one reading with a printable remedy. Reproduced before anything was changed: three such stderrs, driven through `live_open_prs`, all three raising the reported string verbatim.

  **Three states now, and the third is a statement about the probe rather than about the credential.** *Definitely not authenticated* keeps its remedy — `gh`'s own `not logged in` prose, an `HTTP 401` status, `Bad credentials`, or exit 4, which is `gh`'s dedicated auth-configuration code and already had its own class. *Could not tell* is everything else, and it quotes the **exit status and the stderr of the call that did not answer** instead of naming a cause, which is the issue's own fallback. That distinction is not cosmetic: a maintainer loop reading `gh not authenticated` has a documented action — re-authenticate, interactive, outside the loop's authority — where the correct action was to retry. A loop that believes the credential is gone stops; a loop told the tier was unreachable retries and continues.

  **One copy of the predicate, in `_auth_probe.py`** (it landed under `presets/watch/tiers/` and [#1846](https://github.com/Digital-Process-Tools/claude-supertool/issues/1846) moved it to `presets/` hours later, so that the 23 other call sites carrying the same defect could reach it)**.** The GitHub and GitLab tiers are deliberately parallel modules and stay so, but both carried this defect identically and would have drifted apart while being fixed — the argument that already put `_snapshot.py` in that directory. The markers match a **status** and never a number, and the test that keeps a bare status number out of them is structural rather than by example, because a marker list is exactly where this comes back. `_UNREACHABLE_MARKERS` was tightened with the arms it mirrors: a loose entry there is far cheaper, since it produces "could not reach" rather than a false remedy, but two halves of one story disagreeing about what `401` means is how the next reader picks the wrong one.

  **The stderr this now quotes is the remote's text, and it is flattened.** Quoting what failed is the issue's own remedy, and it is also how GitHub's or GitLab's error body gets a say in a line the reader takes as radar's: radar renders a tier failure at column 0 of its own stderr, so a newline in that body puts whatever follows it at column 0 too, in radar's voice. Both tiers now route it through `_untrusted.flat` at the point the value is bound, which is what the op-level twins (`presets/github/prs.py`, `presets/gitlab/mrs.py`) already did to exactly this value and neither tier did. Found by the audit pass rather than by the fix: the not-authenticated arm used to be a fixed string with no interpolation at all, so adding the evidence to it is what widened the surface — worth saying, because the remedy for one defect created the route for another, and three pre-existing arms in the same function had been quoting it raw the whole time.

  **The positive controls are the test.** An assertion that the remedy is absent passes on a tier that has stopped printing anything at all, so every "must not say it" case is paired with a "must still say it" case driven through the same fake — four of the first fourteen cases were green before the fix and stayed green after, and ten were red first. The three flattening cases were red first too, against the already-fixed tiers.
