- **The raw-command guard's refusal for a `-R`/`--repo`-qualified `gh pr diff`/`gh issue view` now points at a working cross-repo route instead of the same-repo-only op it just refused** ([#2404](https://github.com/Digital-Process-Tools/claude-supertool/issues/2404)). `gh pr diff N -R owner/repo` matched the same `replaces` entry as the plain form, so the refusal's `Use:` line named `gh-pr:NUMBER:diff` — which reads the CURRENT REPO, silently dropping the `-R` target rather than pointing at one that already reaches it. The fix prefixes the hint with `repo:OWNER/NAME ` (`repo:` op chaining, `presets/_repo_target.py`) whenever the blocked command carries `-R`/`--repo` and the matched op actually reads a repo target; a malformed or GitLab-shaped value is omitted rather than echoed back as a working alternative.
