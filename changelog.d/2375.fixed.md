- **The `mypy` validator adapter now separates its options from the file argument with `--`, matching every sibling adapter** ([#2375](https://github.com/Digital-Process-Tools/claude-supertool/issues/2375)). `validators/mypy/mypy.py` appended the target path as a bare trailing operand, so a flag-shaped path (`--python-version=3.9`) was read by mypy's own option parser instead of being treated as a positional file -- the `splices` class this repo's ranking table names: a value reaching a subprocess argv where the callee's own parser decides what it means. `ruff`, `actionlint`, `git-status` and `new-file-lint` already guarded their own `subprocess.run` calls the same way; mypy was the one departure.
