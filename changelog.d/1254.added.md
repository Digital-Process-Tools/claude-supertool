- **`jit-index` — a jit-context rule whose regex the matcher cannot honour is refused at write time** ([#1254](https://github.com/Digital-Process-Tools/claude-supertool/issues/1254)). A `**/00-manual/00-index.tsv` row is an ordinary `paste` or `edit`, so nothing in the write path ever looked at its `match` column, which is compiled by **awk** rather than PCRE (`pre-tool-hook.sh:80`, `pre-path-hook.sh:105`). The one-true-awk that macOS ships drops an escape it does not define, so `gh\s+pr` compiles to `ghs+pr` and matches nothing. Two of the seven tool rules were dead this way on 2026-08-10, both the `block` ones; one had never fired since the day it was written, and nothing anywhere said so.

  **The check is structural, not a compile, and that is the decision the issue left open.** awk does not *fail* to compile `\s` — it compiles it, silently, into the wrong thing and exits 0, so an adapter that hands each pattern to the local awk and reads the exit status returns a clean verdict on the exact row that produced the issue. The load-bearing half is therefore a property of the pattern text: an escaped ASCII letter or digit that awk does not define is dropped and the pattern matches the bare character. That catches `\s`, `\d`, `\w` and the construct nobody has listed, and it answers the same on ubuntu, macos and windows — which is the point, since the verdict must not become a statement about the runner. A pattern has to survive the most conservative POSIX awk, because compiling under gawk is not a licence to write `\s` for a hook that fires on somebody's Mac.

  A compile pass against the installed awk still runs, for the failure only a real engine can report: a malformed pattern such as `gh[a` is a **fatal** awk error, and both hooks are invoked as `bash "$S" || true`, so one unbalanced bracket does not disable one row — it silences every rule in the file. Two further dead constructs are refused on the same grounds: `\b` is a backspace to awk rather than PCRE's word boundary, and the tools matcher lowercases the command before matching, so an uppercase literal outside a bracket expression can never match.

  Three states. `skipped` when the file is not a jit-context index, or when awk is absent *and* the structural half found nothing — a half-run check is not a pass. A structural *finding* is still published without awk, because declining to answer must never suppress an answer already in hand.
