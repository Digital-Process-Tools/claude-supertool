- **`test_hint_points_at_the_fix_1489`'s tie-count assertions checked a bare substring against the whole `op_edit` refusal, including pytest's own `tmp_path` — so a machine whose session counter rolled past 19000 failed on the digits `-19` appearing in the path, not in the hint** ([#2083](https://github.com/Digital-Process-Tools/claude-supertool/issues/2083)). Every diagnostic assertion in the file now checks the hint text after the `ERROR: old string not found in <path>` line rather than the whole string, through a new `_hint()` helper; a regression test builds the colliding path shape directly and a paired positive-control test confirms a genuinely regressed hint (a negative line number) still fails.
