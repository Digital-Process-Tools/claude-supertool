- **`git-worktrees` can now be told "I wrote this tree myself"** ([#2272](https://github.com/Digital-Process-Tools/claude-supertool/issues/2272)). Its `cannot tell` gap window (a write between 15 minutes and 1 hour old, with an empty cwd scan) conflated a live agent's index write with the caller's own `git merge`/`git push` moments earlier — reproduced live on a sibling repo, where a maintainer's own merge-and-push into a lane's worktree made a later readiness read return `cannot tell`, citing the maintainer's own write, and correctly-followed downstream policy ("`cannot tell` is not `idle`") then blocked a dispatch for a reason unrelated to actual risk. `git-worktrees:PATH:since=SECONDS` (or `since=@EPOCH`) now lets a caller declare a known-good cutoff: any write at or before that instant is attributed to the caller and excluded from the occupancy signal, while a write strictly after it still counts as evidence of a live agent. The declaration is disclosed in the evidence unconditionally, and is refused outright without a `PATH`, since it names a fact about one specific tree rather than a whole board.
