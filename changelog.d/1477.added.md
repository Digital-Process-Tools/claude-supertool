- **`SUPERTOOL_WATCH_NAME` names a whole watch channel, deriving both paths that used to have to agree by hand** ([#1477](https://github.com/Digital-Process-Tools/claude-supertool/issues/1477)). A private channel took `SUPERTOOL_WATCH_SOCK` *and* `SUPERTOOL_WATCH_STATE_DIR`, and setting only the socket is worse than setting neither (#1309): the poller slot is held `O_CREAT|O_EXCL` per state directory (#476), so a second session sharing `/tmp` spawns no pollers at all and both boards render healthy. The two variables are never independently useful — the only arrangement they can express that one name cannot is exactly the broken one.

  The name is an ordinary environment variable, so a non-reserved key in an op's `.supertool.json` block reaches it with no new plumbing. It derives `/tmp/supertool-watch-<name>.sock` and `/tmp/supertool-watch-<name>`, the second created `0700` — and only when it was *derived*: a state directory the operator supplied stays unanswerable when it is missing, which `watch` reports rather than manufacturing (#693).

  **The consumer is the asymmetry, and the check for it is the deliverable.** `claude-channel` is spawned by the harness from `.mcp.json`, never by supertool, so a name in `.supertool.json` configures three of four surfaces and leaves the consumer on the default path — the half-configured state through a new door. `channel.ts` now reads the same variable with the same precedence and derives the same path, and `channel:health` reads `.mcp.json` at the plugin root and at the current directory and compares what each declares against the socket this process uses: they agree, they disagree with both paths named, or nothing was established, which is said rather than rendered as agreement.

  **Precedence is printed, never silent.** An explicit `SUPERTOOL_WATCH_SOCK` or `SUPERTOOL_WATCH_STATE_DIR` overrides the name — it is the value a running poller already captured and cannot migrate away from — and the report names both the path in force and the path the name would have produced. A name that is not usable as a path component is ignored and said so, leaving the channel on the defaults rather than on half a private one.
