- `radar`'s `_arg` was handed to every registered tier instead of only the tier whose name prefixes it, so a `gh-`-prefixed argument also reached a `gl-issue` tier configured alongside it, which either ignored it or misread it silently. `_arg` is now routed to the matching tier only, and an argument that matches no registered tier's name is reported as a warning instead of being handed to one that will misread it (#2644).
