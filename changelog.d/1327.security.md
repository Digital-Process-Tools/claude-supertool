- **Named the substring-host hazard `origin_slug`'s docstring sold as a feature without ever admitting** ([#1327](https://github.com/Digital-Process-Tools/claude-supertool/issues/1327)). `origin_slug`'s `host_substr in host` test is deliberate -- it is how a self-hosted GitLab at `gitlab.internal.example` matches `"gitlab"` -- and it is safe only because the value under test is always the operator's own `git remote get-url origin`, never text an issue body, a PR title or any other untrusted source could influence. The docstring now names both halves explicitly: the operator-controlled condition that makes the substring safe, and a concrete lookalike (`evil-github.com`) a caller passing it anything else would match. Behaviour is unchanged -- this is the documentation-only option the issue lists, not the exact/dot-suffix alternative.
