- **A Python formatter now ships: `ruff-format`** ([#2085](https://github.com/Digital-Process-Tools/claude-supertool/issues/2085)). The three formatter adapters that shipped under `formatters/` were PHP, PHP and JS/CSS -- a 1148-file Python repository (this one) had no `format:PATH` route onto its own tree at all. `formatters/ruff-format/ruff-format.py` runs `ruff format` and emits the SCHEMA.md shape (metrics, structured errors), matching `php-cs-fixer`/`phpcbf`/`prettier-write`. `ruff format` rather than `black`: this repo's own CI lint leg already depends on ruff, so the toolchain is already installed wherever the tests run.

  The adapter is **not** wired into this repo's own `.supertool.json` `formatters` block. `ruff format --check _supertool.py` reformats the file by over 13,000 diff lines under `ruff format`'s own house style, which this codebase does not follow -- registering it with `hooks_into` would silently rewrite the whole file the next time anyone made a one-line `edit` to it, exactly the risk this issue's own text warns about. A repo whose Python already matches `ruff format`'s style can wire it in the same way `php-cs-fixer`/`phpcbf` are wired for PHP repos.
