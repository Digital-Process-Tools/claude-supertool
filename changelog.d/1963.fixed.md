- **Fixed `gh-branch`'s watch source stamping a fork checkout's events with the fork instead of the repository `gh` actually queried** ([#1963](https://github.com/Digital-Process-Tools/claude-supertool/issues/1963)). `transport.repo_slug()` reads `origin`'s remote once per poller process, which is right for a source with no better answer of its own — but `gh-branch` has one: it already resolves the repository through `gh` itself to run `_head_commit`/`_run_list`, and in a checkout whose `gh repo set-default` points at a parent repository that answer can disagree with `origin`. The event now carries the repository `gh` actually queried, and the dispatcher prefers a source's own answer over the process-level one when it has one; every other source is unaffected.
