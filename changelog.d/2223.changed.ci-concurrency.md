- **CI runs one matrix per ref, and a superseded run is cancelled** ([#2223](https://github.com/Digital-Process-Tools/claude-supertool/issues/2223)). `tests.yml` and `changelog.yml` declare a `concurrency` group keyed on `github.ref` with `cancel-in-progress: true`. Neither declared one before, so a maintainer tick's merge train queued a full sixteen-leg matrix per squash: six were queued on `master` at once on 2026-09-03, and the run for the head anyone wanted an answer about had started no leg seventeen minutes after its merge. On `pull_request` this costs nothing, since a force-push makes the older run worthless. On `push: master` it trades away the ability to bisect a red to the merge that caused it, taken deliberately because nothing here reads a per-commit historical green.
