- **`GLAB_BIN` / `RUFF_BIN` silently stopped resolving the binary at its own default Windows install location.** Both `validators/ci-lint/ci-lint.py` and `formatters/ruff-format/ruff-format.py` shared the identical idiom for turning the env var into an argv prefix: convert backslashes to forward slashes, then `shlex.split(..., posix=True)`. That split is real work -- this repo's own cross-platform test stubs rely on passing a shlex-quoted multi-token command line (`python /path/stub.py`) through the same env var -- but an UNQUOTED single path containing a space, e.g. the default `C:\Program Files\glab\glab.exe`, split at the space too: the adapter took `C:/Program` as the binary, reported `GLAB_BIN not found: C:/Program`, and the validator/formatter went silent on any Windows machine with the tool installed under `Program Files`. It landed in the "binary absent" arm rather than crashing, so no edit was rolled back -- a silent-off, not a silent-corruption. Both adapters now share `validators/common/bin_resolve.resolve_bin_cmd()`, which tries the raw value as one whole path FIRST and only falls back to `shlex.split` when that does not resolve to a real, executable file -- so a legitimate single path with a space in it is never torn apart, while the shlex-quoted multi-token form the test stubs use keeps working exactly as before.
