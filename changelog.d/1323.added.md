- `gh-issues:iids=1233,1240,1251` — look up an exact set of issue numbers in one call, for auditing citations. Every requested number gets its own row: the issue, `is a PR` for a number that is a pull request here, `not an issue` for one that resolves to nothing, and `lookup failed` for one the call could not reach — never a silently shorter list, which an audit reads as "these all check out". Filed as a new `gh-titles` op; built as a filter on `gh-issues` instead, so it inherits `per=`, the disclosure machinery and the refusals rather than growing a second render of the same model. `per=` caps it and says how many numbers it did not look up; the `--limit N — more may exist` sentence is never printed, because the population is the one the caller typed. A listing filter beside `iids=` is refused rather than dropped ([#1323](https://github.com/Digital-Process-Tools/claude-supertool/issues/1323)).
- Board rows now show `[closed]` for a closed issue and `[state:?]` when gh did not say. `state=all` and `iids=` both render closed issues, and one that looked identical to an open one answered "is this citation still live" wrongly.
