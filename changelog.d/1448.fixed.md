- `git-push` now relays the local pre-push hook's own output, so a gate that
  announces it is not gating is heard (#1448). Since #894 and #1242 the hook is
  selective — it runs the full suite for `master`/`main` and deliberately skips
  it for a feature branch — and it says which arm it took every time. None of
  that reached the operator: two pushes 30x apart in wall clock (7.45s and
  226.99s, the second running ~9,600 tests) produced receipts of the same shape,
  so a skipped suite and a passed one were indistinguishable and "it pushed
  fine" carried a local-green claim it had not earned.

- The relay is verbatim, never a summary: the op asserting what the hook did is
  the inference it refuses everywhere else. The hook's lines are told apart from
  git's own by process ordering, not by pattern — git prints its `To <url>`
  porcelain header only after the hook has exited, so everything above it on
  stdout was written by the hook and nothing below it was. With no header there
  is nothing to delimit against, and the receipt says the boundary is unknown
  instead of claiming the stream. A long transcript keeps its first three and
  last twelve lines (a hook announces its arm first and its outcome last), and
  the elision is named rather than silent.

- Above the relay sits a state line in three states: the hook path when one ran,
  `none ran` with the reason (including `--no-verify`, now disclosed rather than
  left as a bare flag name), and `UNKNOWN` when git did not answer where the
  hook lives. It is what makes an empty relay readable, since a hook that
  printed nothing and no hook at all are different facts that render alike.

- The `--- git output ---` dump on a refused push is bounded the same way, at
  five lines and thirty (#1448). It used to print the child's whole output, and
  when the thing that refused the push is a hook running the suite that is an
  11,449-item pytest transcript inside a receipt. Both ends survive, which is
  where the arm the hook announced and the tests it refused on both live.

- The timeout receipt keeps everything #1242 and #1447 put in it and gains one
  sentence: a timed-out push is killed and its captured output goes with it, so
  a missing relay there is not a hook that stayed silent.
