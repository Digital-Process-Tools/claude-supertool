- **`mypy` validator adapter** — a second Python type-checker alongside `pyright`, coexisting rather than replacing it: different findings, not a subset ([#669](https://github.com/Digital-Process-Tools/claude-supertool/issues/669)). `mypy --output json --no-error-summary`, one JSON object per line rather than pyright's single envelope, parsed with `validators/common/linebreaks.split_lines()`. `--cache-dir` pinned to `os.devnull` (mypy's own documented switch, confirmed against `mypy/main.py`) so running it never leaves a `.mypy_cache/` behind in the caller's cwd. Absent tool, a non-JSON fatal exit, and a timeout are all the third state or a loud `adapter` finding, never a fabricated `ok: true`.
