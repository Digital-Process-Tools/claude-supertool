- **A discarded shell segment the guard could not render faithfully was presented the same as one it could, under an instruction to re-send it verbatim** ([#2023](https://github.com/Digital-Process-Tools/claude-supertool/issues/2023)). `_guard_raw_segment_spans` does not special-case the handful of all-punctuation-word shell idioms `shlex.shlex(punctuation_chars=True)` treats as pseudo-separators (a bare `{}`, an escaped `;`), so a span containing one -- `ls | xargs -I {} rm -rf {} && gh pr view 1`'s `xargs`/`rm` half, for instance -- fell back to a word-rejoin that renders three separate commands, dropping the `{}` placeholders that bind them. The discard line now marks that text as unable to be rendered exactly, rather than folding it into the same "re-send them separately" instruction as a faithfully sliced segment.
