- **`KNOWN_RESIDUE` in `tests/test_markdownlint_noise_2012.py` is now keyed by `(file, rule_id)` instead of by file alone** ([#2598](https://github.com/Digital-Process-Tools/claude-supertool/issues/2598)). A per-file exemption made a *second*, unrelated markdownlint rule landing in an already-exempted file invisible to the residue test -- only the repo-wide `FINDINGS_CEILING` would ever have caught it, with 13 findings of headroom. `_lint_all_tracked_md_with_rules()` now keeps each finding's own rule code, and `_residue_violations()` checks per (file, rule) pair.
