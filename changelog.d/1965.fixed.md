- **Fixed `gh-branch`'s watch source emitting `went_green` for a branch whose repository it could not identify** ([#1965](https://github.com/Digital-Process-Tools/claude-supertool/issues/1965)). A `gh repo view` failure inside the same composition that resolves the commit and its runs was discarded, and the routing key, the desktop notification and `lookup="ok"` were byte-identical to a real green — the only trace was prose inside the event's `sentence` field, which this repository's own shipped MCP instructions tell a consumer to route on nothing but. That failure now routes through the same `branch_unreachable` / `LOOKUP_UNAVAILABLE` arm a commit or run-list lookup failure already used, per this composition's own rule that a `gh` which could not answer at all must never reach a state — GREEN included.
