- **Fixed a coincidental-digit false positive in `test_watch_channel_collision_2133.py`'s negative control** ([#2301](https://github.com/Digital-Process-Tools/claude-supertool/issues/2301)). The test used a bare `"9999" in report` / `"9999" not in report` substring check as its signal for "a rival consumer's refusal was recorded", but the same report legitimately contains the test's own `AF_UNIX` socket path, built from a nanosecond timestamp (`time.time_ns()`) that can coincidentally contain that same four-digit run -- observed for real on CI (`ubuntu-latest, 3.9`, run 33938827428, commit 45c3a33, `.../8575413370999984.sock`). Both assertions now check for the literal `"pid 9999"` that `channel._refusal_lines` actually renders for a recorded refusal, which cannot collide with an unrelated path. A new regression test forces the exact coincidence deterministically (a socket path built to contain `"9999"` with no refusal recorded) rather than relying on `time.time_ns()` to reproduce it.
