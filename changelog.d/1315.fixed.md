- **`gl-pipeline:ID:full` and `mcp_stop:--all` are now declared where callers read them** ([#1315](https://github.com/Digital-Process-Tools/claude-supertool/issues/1315)). Both tokens already worked -- `gl-pipeline`'s `_FILTERS` accepted `full` and `mcp_stop`'s underlying script treated `--all` identically to the dedicated `mcp_stop_all` op -- but neither `syntax` string nor description named them, so a caller who guessed either spelling got a working call the registry never told them about. `gl-pipeline`'s `syntax` and refusal text now name `full` explicitly; `mcp_stop`'s description now says `--all` reaches the same code path as `mcp_stop_all`, which stays the canonical spelling.
