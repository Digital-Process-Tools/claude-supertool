- **A watch event names the repository, not only the pull request number** ([#1952](https://github.com/Digital-Process-Tools/claude-supertool/issues/1952)). A `github-pr` watcher's event carried no repository anywhere a reader sees -- a desktop notification or an MCP `<channel>` tag read as `github-pr 527: merged`, ambiguous across every repository by construction, because every repository has a `#527`. The repository was recoverable from `url`, but `url` never reaches the body line a human actually reads. Every poller now resolves its own `origin` remote once per process (`transport.repo_slug()`, forge-agnostic: `git@HOST:PATH.git` and `https://HOST/PATH` alike) and carries it on the event's envelope beside `source` and `id` -- the poller's own configuration, never the forge object being polled, so a payload key of the same name cannot override it. `claude-channel` renders it as its own attribute (`repo="OWNER/REPO"`) and folds it into the summary line: `github-pr OWNER/REPO#527: merged`. Absent, never guessed, when the remote could not be resolved.
