- **`payload-lint` now refuses extra colon-separated tokens instead of silently dropping them** ([#2238](https://github.com/Digital-Process-Tools/claude-supertool/issues/2238)). The op is dispatched via `parts[1]` only (the `@file`/`@-` reference), but was missing from `_MAX_COLON_SLOTS`, the table `payload-lint:@file:extra:more` ran with `extra`/`more` silently dropped — the same defect #1582 refused for every other fixed-slot op. `payload-lint` is now in that table with its one-slot arity, so an extra token is refused with the same `ERROR:` message the rest of the table already gives.
