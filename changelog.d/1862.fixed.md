- **A CI budget floor sat below the duration it exists to protect** ([#1862](https://github.com/Digital-Process-Tools/claude-supertool/issues/1862)). `coverage`'s floor in `tests/test_ci_job_timeouts_722.py` was 8 minutes — 480s — against a worst observed CI run of **528s**. The floor's whole job is to make *tightening* a budget fail there rather than in a red leg nobody caused, so a floor under the job's own worst run permitted exactly the tightening it was written to refuse. It read as safe because it was derived from four *local* runs (3m24s-6m04s), and local was faster than CI; the workflow comment beside the budget claimed "~3.3x the worst observed run" where the real CI ratio is 2.3x. Raised to 18.

  Found by doing what the issue asked. #1862 was filed on a stale comment — `lint-new` (#1481) "has never run, so its pair is by analogy" — which had been false on every push since #1481 shipped. Measured 2026-08-20 over the 14 most recent successful `tests` runs, `lint-new` takes 13-33s against a 10-minute budget, so **its number does not change**; only its warrant does, from a guess that happened to land somewhere defensible to a measurement. The finding was one job over.

  Every job class had also got slower without anything noticing: `notifiers` 24-37s to 47-70s, the ubuntu pytest legs 93-125s to 150-301s, over nineteen days. Nothing compared a budget to a duration — only to a hand-written floor.

  **On whether a "no data exists yet" claim should carry something a test can invalidate: yes, and it now does — partially, with the gap stated.** `OBSERVED_WORST_SECONDS` records the worst run per job class with its date, and `test_every_budgeted_job_has_a_measurement` refuses a job that carries a `timeout-minutes` and no measurement, so a new job cannot be sized by analogy in silence the way `lint-new` was. `test_the_floor_clears_the_duration_it_exists_to_protect` is what caught `coverage`. What no offline test can check is whether the date is current — a table untouched for a year reads exactly like one taken this morning — and that limit is written beside the table rather than left to be discovered.
