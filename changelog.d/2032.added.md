- **A `slack` publish preset (`slack_publish`), for a deliberate post rather than a fire-and-forget ping** ([#2032](https://github.com/Digital-Process-Tools/claude-supertool/issues/2032)). `slack_publish:CHANNEL_ID|TEXT[|THREAD_TS[|force]]` calls `chat.postMessage` and returns the posted message's own `ts` — the value a later thread reply or edit needs — plus a permalink when that lookup succeeds. This is not a duplicate of the Slack webhook notifier already documented in `docs/notifiers.md`: that one is fire-and-forget, fires on a glob match against a file event, has no return path, and carries none of the outbound safety gating (`presets/_publish_safety.py`) this op runs under. Marked `!` in `ops:roster` — it changes something outside this tree, and is documented rather than probed for. No new dependency: `presets/_http.py` for the request, `presets/_secrets.py`'s existing `xox[abprse]-` redaction rule for anything that leaks into an error message.
