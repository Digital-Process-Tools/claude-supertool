- **`_init_platform`'s github/gitlab asymmetry now explains itself where it lives, not only at the top of the function.** The github branch is an exact host match (`host == "github.com"`) for the #1212 spoof reason (`evilgithub.com` must not read as `github.com`); the gitlab branch is a deliberate substring match (`"gitlab" in host`) so a self-hosted instance like `gitlab.dp.tools` still resolves, mirroring `presets/_remote_default.py`'s `origin_slug`. The function docstring already argued this, but a reader skimming just the two `if` lines could plausibly read the #1212 comment on the github line as covering both branches and "fix" the gitlab line into the same exact match, silently breaking self-hosted GitLab support. Each branch now carries its own inline comment, and `tests/test_init_platform_2175.py` pins both behaviors (`github.com` exact, `evilgithub.com` refused, `gitlab.com` and `gitlab.dp.tools` matched, `notgitlab.com` accepted as the documented tradeoff) so a future edit that makes the two branches "consistent" in either direction goes red instead of drifting.
