- **A doubled backslash in a payload field that gets WRITTEN is now refused, instead of noted after the bytes land** ([#1087](https://github.com/Digital-Process-Tools/claude-supertool/issues/1087)). A triple-single-quoted literal block processes no escapes, so `\\d` in `new` or `content` reaches the file as two characters — and that file passes every validator, because two backslashes are legal in nearly every language this repo edits. The write was wrong only in string contents, so nothing downstream fired and the author found out from behaviour, usually a CI round later. `old` keeps the note: it is an anchor, a doubled one cannot match, and the runner already reports the skip.

  **The refusal is suppressible, and that is the whole reason it can exist.** `literal_backslashes = true` at the top level of the payload says the pair is deliberate ([#1096](https://github.com/Digital-Process-Tools/claude-supertool/issues/1096)). Refusing an arbitrary-offset pattern with no way out would make correct content unwritable at every offset — a LaTeX line break, a Markdown hard break, `"C:\\Users"` in a non-raw Python string — which is the loud-for-quiet trade this repo rules out by name. A suppressible refusal records the decision in the payload; an unsuppressible warning makes it on the author's behalf.

  **Behaviour change worth knowing about:** the refusal is not scoped by target language, unlike [#835](https://github.com/Digital-Process-Tools/claude-supertool/issues/835)'s shell-line guard. It reads the payload's escape reflex, not the file's grammar, so a `.tex` or `.md` write carrying a deliberate pair now costs one key. Setting the flag inside an `[[ops]]` table is refused rather than ignored — a flag whose apparent scope is not its real scope is a worse lie than the one being fixed.

  **And the note names which op it means.** On a six-op batch it printed a bare `new` and then `and 1 further field`, so the reader re-derived by hand which op had been affected. Fields are labelled `ops[2].new` now, and the overflow line lists the ones it elides instead of counting them.
