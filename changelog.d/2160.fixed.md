- **`formatters/ruff-format/ruff-format.py` now closes both file handles it reads through, explicitly** ([#2160](https://github.com/Digital-Process-Tools/claude-supertool/issues/2160)). Both the before-format and after-format reads were a bare `open(file, ...).read()` chain with no context manager -- the handle was only ever closed by CPython's refcounting dropping the last reference, timing this adapter does not control on other implementations, and not guaranteed even on CPython to happen before an exception's traceback finishes propagating. Both sites now use `with open(...) as f: ... = f.read()`. Flagged by CodeQL on PR #2158 and filed as a follow-up rather than blocking that merge.
